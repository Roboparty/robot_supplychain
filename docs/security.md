# 入库纪律

本仓库按「可公开协作」标准维护。

## 可以入库

- 流程框架、Gate、RACI  
- 门类选型口径、验收抽检项、典型交期量级（区间，非某家合同价）  
- 脱敏后的踩坑结论（不出现个人手机/微信）  
- 清单与卡片模板  

## 不可以入库

- 密钥、token、`.env`、私钥、密码  
- 完整合同扫描件、未脱敏对公账号、身份证等 PII  
- 供应商完整电话 / 个人微信  

摘要可以：「某类减速器国内龙头交期约 x–y 周」——可以。  
「张工 138xxxx 微信 xxxx」——不行。

## 提交前自检

1. `git status` 里有没有 Excel 全量通讯录、PDF 合同、截图二维码  
2. 新增 Markdown 表有没有「电话 / 微信 / 邮箱」列  
3. 不确定就先不 add，标 `安全: 拦截` 并说明  

分类标签：`安全: 公开` · `安全: 脱敏` · `安全: 拦截`。
