# 成本与交期

## 成本怎么拆

不要只记「一颗多少钱」。至少拆成：

| 块 | 问什么 |
|---|---|
| 材料 | 牌号、厚度、替代是否允许 |
| 加工 | 机床类型、装夹次数、公差带 |
| 后处理 | 阳极 / 喷涂 / 热处理是否外发二次 |
| 样品费 | 是否可抵批量；模具 / 夹具谁出 |
| 物流与包装 | 电池、精密件是否要特殊包装 |
| 账期 | 含税口径、预付比例、质保金 |

## 交期倒排

```text
需要上线日
  − 装配缓冲
  − 物流
  − 加工 / 生产周期
  − 打样 + FAI（若必须）
  − 询价窗口
  = 最晚冻结图纸日（G0/G1）
```

长周期器件（伺服芯片、特定电芯、进口编码器、谐波）在 **G0 就要标红**，不要等结构件图纸齐了才发现电子要 16 周。

## 常见幻觉

- 「样品 7 天」不含排队、不含表面处理外发。
- 改一个倒角等于新交期，不是插队。
- 含税 / 未税混比，看起来便宜 13%。
