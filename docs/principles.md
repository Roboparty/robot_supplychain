# 原则

早期机器人供应链最容易在三件事上翻车：图纸没冻就下单、到货不检就上线、出问题靠微信私了。下面几条是压仓石。

## 1. 三条铁律

| 铁律 | 含义 | 反例 |
|---|---|---|
| 无冻结图纸/规格不下正式单 | 料号、版本、材料、表面处理、接口必须写死 | 「先按上次那版做，改了再说」 |
| 无 IQC 不发料 | 未检品隔离；Pass 或书面 Conditional 才能领用 | 快递拆开直接给装配 |
| 无 NCR 不私下让步 | 不合格走记录；让步必须会签、限批次 | 「差不多能装就行」 |

安全、高压电气、承力结构件：**不允许口头让步**。

## 2. 先锁范围，再谈价格

G0 没冻（买什么、买几套、哪些必须打样）时，询价和比价都是空转。  
目标单价可以有，但不能用目标单价倒逼还没冻结的规格。

## 3. P0 料至少两家可询

独家件必须单独标明原因和备份计划（第二来源或安全库存）。  
「只有这一家会做」可以是事实，但不能是默认状态。

## 4. 比价不只看单价

书面报价至少看：含税口径、MOQ、交期、样品费、账期、不良/返修政策、沟通响应。  
P0 料书面报价 ≥2 家；独家件写进卡点，不藏在聊天记录里。

## 5. 升版 = 旧报价作废

图纸或规格升版后，旧 RFQ / 旧单价默认失效。  
禁止「改了三个孔还按上周那张报价下单」。

## 6. 对账只认 PO

口头和微信可以推进沟通。数量、交期、版本、收货地址、付款条件以 PO（或书面变更）为准。

## 7. 可公开协作的才入库

本仓库默认按可公开协作标准写：框架、清单、脱敏后的结论。  
完整合同、密钥、身份证、对公账号、供应商完整电话/个人微信 **不入库**。
