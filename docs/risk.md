# 供应链风险

试点阶段优先盯这些，不建复杂风控模型。

| 风险 | 信号 | 默认对策 |
|---|---|---|
| 独家料 | P0 仅 1 家可供 | 第二来源验证，或安全库存 + 规格开放 |
| 图纸不冻 | 每天改接口 | 停询价，先 G0 |
| 交期承诺虚 | 样品节点连续跳票 | 降权；关键件并行第二家打样 |
| 质量不稳定 | 同厂重复 NCR | 暂停新单，先闭环再评分 |
| 电池 / 危货 | 无认证、混放待检 | 隔离规则 + 运输资质 |
| 商务不清 | 无开票、无质保路径 | 未准入不下正式 PO |
| 技术串行 | 供应商介绍与门类对不上 | 以官网 / 样品数据为准，原表当线索 |

## 准入最低线（未达标可要意向价，不可下 PO）

- 能开增值税发票
- 能提供样品交期与 MOQ
- 有返修 / 退换路径
- 图纸保密可执行（NDA 或合同条款）
