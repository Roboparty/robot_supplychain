# 压铸

**大类：** [结构件](./README.md)

## 1. 是什么

铝合金/锌合金模具浇出来再 CNC 后加工。适合复杂腔体和小批壳体。开模前必须冻结外形、壁厚、抽芯和装配接口。

## 2. 在机器人里干什么

关节外壳、驱动盒、复杂一体壳体。样机阶段能 CNC 替代就不要开模。

## 3. 选型必须冻结

- [ ] 合金牌号（ADC12 / A380 / AZ91 等），不要写「铝」或「镁」。见 [铝](./materials/aluminum.md)、[镁](./materials/magnesium.md)
- [ ] 后加工余量
- [ ] 分型、抽芯、浇口是否影响安装面
- [ ] 哪些面要 CNC、公差多少
- [ ] 模具改模次数上限

## 4. 配套关系

见 [表面处理](./surface/README.md)。压铸铝装饰阳极容易发花，外观优先喷粉；气孔在密封面、螺纹和喷粉鼓泡处要特别检。

## 5. 验收要点

关键安装面平面度、螺纹、气孔、重量（壁厚漂移）。

## 6. 已知坑

- 样机 CNC 件没有拔模角，开模后装配干涉。
- 气孔在轴承室，装上才漏脂或精度差。
