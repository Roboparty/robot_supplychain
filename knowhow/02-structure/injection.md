# 注塑

**大类：** [结构件](./README.md)

## 1. 是什么

塑料开模件。外观、卡扣、绝缘罩常用。承力结构不要默认注塑。

## 2. 在机器人里干什么

外壳、指面、线卡、非承力装饰。样机用 3D 打印验证外形，确认后再开模。

## 3. 选型必须冻结

- [ ] 材料（PC / ABS / PA+纤 等）、收缩率
- [ ] 外观面、色号、是否喷漆
- [ ] 嵌件、壁厚、卡扣寿命
- [ ] 年用量能否摊模具

## 4. 配套关系

与钣金/CNC 的卡扣和螺钉柱要对拔模。阻燃等级若进电器盒要写死。

## 5. 验收要点

外形、色差、卡扣力、嵌件拉拔。

## 6. 已知坑

- 打印件验证通过就开模，壁厚和圆角未按注塑重评。
- 玻纤料磨损对配的铝件。
