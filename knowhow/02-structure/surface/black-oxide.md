# 发黑

**大类：** [结构件](../README.md) · **小类：** [表面处理](./README.md)

钢和铸铁表面生成一层很薄的黑色氧化膜（主要是四氧化三铁），再浸油。几乎不改尺寸，防腐很弱，靠油膜。不是铝的黑阳极，也不是 QPQ。

## 和容易混的工艺

| | **碱性发黑** | **常温发黑** | **磷化** | **QPQ / 盐浴氮化** |
|---|---|---|---|---|
| 基材 | 碳钢、合金钢、铸铁 | 钢 | 钢 | 钢 |
| 膜 | < 1 μm 氧化膜 | 更薄、结合差一档 | 磷酸盐数 μm | 化合物层大约十几 μm，还有扩散层 |
| 尺寸 | 可忽略 | 可忽略 | 很小 | **有变化**，精密轴要留量 |
| 硬度 | 没有 | 没有 | 没有 | 有，耐磨 |
| 防锈 | 必须浸油，室内轻防锈 | 更依赖油 | 浸油或当喷漆底层 | 明显好于发黑 |
| 机器人 | 钢支架、销、非外观结构 | 便宜件，少用于承力外观 | 喷漆前、油封防锈 | 轴、滑块；**不要写成发黑** |

铝件要黑色外观，走 [阳极](./anodize.md)，不要下「发黑」。不锈钢发黑是另一套化学染黑，膜更脆，和碳钢碱性发黑不是同一 PO 描述。

## 碱性发黑在机器人里

关节里钢件不多：销轴、垫片、个别支架、工装。发黑的价值是 **不改变配合**、成本低、看起来统一。它不提供盐雾意义上的户外防腐。图纸写「发黑」却验收 48 h / 96 h 盐雾，会整批退。

流程口头是：除油 → 酸洗 → 发黑槽（热碱）→ 水洗 → 浸脱水防锈油。油膜被溶剂洗掉，防锈就没了。装配前用溶剂大洗，等于把保护洗掉。

高强钢（紧固件 10.9 及以上、弹簧）酸洗有氢脆风险。这类件发黑要问清是否酸洗、要不要除氢。优先买成品等级件，不要结构件和螺栓混槽。

## 磷化什么时候用

要喷漆的钢件，磷化比发黑适合当底层。锰系磷化吸油，用于滑动防锈；锌系更常当涂装底层。磷化后不涂油、不喷漆，裸件防锈有限。

## 选型必须冻结

- [ ] 碱性发黑 / 常温发黑 / 磷化 / QPQ，四者写全名  
- [ ] 浸油种类；装配时允不允许洗油  
- [ ] 盐雾 **不写** 或按发黑+油的真实能力写，不套镀锌指标  
- [ ] 精密轴若是 QPQ：化合物层厚度、处理前后尺寸  
- [ ] 不锈钢单独注明，不和碳钢同一工艺  
- [ ] 弹簧、10.9 以上螺栓不进结构件发黑批  

## 验收

- [ ] 颜色均匀，无红锈、无大块花斑  
- [ ] 关键配合仍过塞规（发黑不应改变尺寸；变了说明做成了别的工艺或挂渣）  
- [ ] 油膜在；包装不互相粘成锈点  
- [ ] 螺纹通止  

Fail：铝件发黑、发黑件要求厚膜硬度、未浸油已见锈、QPQ 轴按发黑零尺寸变化去配。

## 坑

- 「黑色钢件」采购发成镀黑锌，尺寸和导电都变了。  
- 发黑后整件泡清洗剂，库房一周起锈。  
- 把 QPQ 的耐磨当发黑的免费赠品。
