# 微弧氧化

**大类：** [结构件](../README.md) · **小类：** [表面处理](./README.md)

微弧氧化（MAO / PEO）是在铝、镁、钛表面用较高电压打出陶瓷氧化膜。它不是更厚的 [硬质阳极](./anodize.md)：槽液、电源、粗糙度和外观都是另一条工艺。

| | **微弧氧化** | 对照 |
|---|---|---|
| 基材 | 铝、镁、钛（阀金属） | 钢做不了；钢走发黑 / 喷涂 |
| 膜 | 陶瓷氧化层，常分疏松外层和较致密内层 | 普通阳极是薄氧化膜，可染色 |
| 膜厚口头 | 防腐常约 10–30 μm；耐磨常约 30–60 μm | 再厚，粗糙、尺寸和疲劳一起变差 |
| 外观 | 哑光，灰、白、褐，色差大 | 染不出阳极那种均匀黑 |
| 电 | **绝缘**，击穿电压高 | 接地仍要留金属面 |
| 尺寸 | 明显变厚，孔缩小、外圆变大，粗糙度上升 | 不能套用普通阳极「一半膜厚」去估 |
| 机器人 | 镁合金骨架、要耐磨防腐又不能加钢的铝件 | 6061 外观件仍用普通阳极 |

硬度在陶瓷膜上，基材还是铝或镁。它不替代轴承，也不替代钢销。

## 什么时候用

- **镁合金**（AZ31、AZ91 一类）几乎不能靠装饰阳极做防腐，微弧氧化是常见陶瓷膜。  
- **压铸铝** 装饰阳极容易发花；要耐磨防腐、不追求亮黑时，微弧氧化往往比黑阳极匀。外观罩仍优先 [喷粉](./coating.md)。  
- **6061 外观法兰** 要均匀黑：用普通阳极，不要改微弧。  
- 和硬质阳极二选一：滑动耐磨、膜可以灰、预算紧，硬质阳极往往够；要更厚的陶瓷、或基材是镁，再谈微弧。

## 尺寸和表面

外层疏松，粗糙度会从机加的 Ra 0.8 量级升到数微米。配合面、密封面、轴承室默认 **保护**，或微弧后局部磨掉。螺纹、销孔不保护会装不上，攻丝会掀膜。

尖角、薄壁容易烧穿。图纸上的锐边要倒角，壁厚太薄的罩不要整件微弧。

挂具点会留疤，指定在非配合、非外观面。

## 选型必须冻结

- [ ] 写全名「微弧氧化」，不要写成硬质阳极或阳极加厚  
- [ ] 基材牌号（铝 / 镁 / 钛）  
- [ ] 膜厚范围；配合尺寸是处理前还是处理后  
- [ ] 粗糙度：配合面保护还是处理后研磨  
- [ ] 颜色只要求「陶瓷灰」还是有色板；不要按 RAL 黑验收  
- [ ] 保护：螺纹、轴承室、销孔、密封面、接地凸台  
- [ ] 是否封孔；盐雾只在图纸写了才检  

已装轴承、磁钢、胶、密封圈、线束的零件不能进槽。

## 验收

- [ ] 膜厚抽检（大面；边角看有没有烧薄或烧穿）  
- [ ] 无大面积剥落、裂纹、烧焦点  
- [ ] 螺纹通止；保护孔塞规  
- [ ] 接地面仍导通  
- [ ] 色差按试样，不按阳极色板  

Fail：当成硬质阳极报价和验收、镁件改发黑、外观件要求阳极黑、精密孔未保护。

## 坑

- 产能比阳极少，交期没单列。  
- 膜厚按耐磨档做上配合面，组件装不上。  
- 薄壁罩尖角烧穿，当来料裂纹。  
- 整件绝缘，屏蔽壳还得返工刮面。
