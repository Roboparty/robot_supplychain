# 喷涂

**大类：** [结构件](../README.md) · **小类：** [表面处理](./README.md)

液体漆、粉末、电泳都是在表面堆一层有机膜。比阳极厚，绝缘，改配合，也能盖住轻微刀纹。接地面、螺纹、轴承室必须保护。

## 三种不要混

| | **喷粉** | **喷漆** | **电泳** |
|---|---|---|---|
| 膜厚口头 | 约 60–120 μm | 约 20–50 μm（看几道） | 约 15–25 μm |
| 外观 | 桔纹，边角偏厚 | 可做平光、高光，色准更好 | 均匀，光泽偏低，复杂内腔也能上 |
| 附着力 / 耐磨 | 外壳最好用 | 看底漆和厚度，边角易崩 | 适合当底或黑盒 |
| 遮盖 | 刀纹、轻微砂眼盖得住 | 薄，缺陷容易现形 | 内腔好，外观装饰一般 |
| 炉温 | 固化常见约 160–200 °C | 低温漆可更低；烤漆同样进炉 | 固化也要进炉 |
| 机器人 | 电池盒、算力盒、防护罩 | 外观罩、补色、塑料件 | 折弯盒、深腔支架 |

色号写 **RAL** 或贴色板。喷粉黑和阳极黑不是同一个黑，装在一起会色差。

## 尺寸和保护

喷粉最容易把件做「肥」：

- 配合止口、定位面、密封面：保护或处理前减尺寸。单边 0.08 mm 量级就能让盒盖装不上。  
- 螺纹孔、PEM 牙：塞子或硅胶。喷死之后攻丝会把周围膜掀掉。  
- 接插件开孔、接地铜柱、屏蔽接触面：必须露出金属。  
- 深腔和内角：喷粉有静电屏蔽，死角偏薄；电泳反而均匀。盒体防锈看内腔，不要只看外表面。  

膜厚是范围不是一个数。图纸写「喷粉 60–100 μm」比「喷粉」有用。

## 什么不能进炉

喷粉和很多烤漆要烘。已经装上的不能一起进：

- 轴承、油封、磁钢、编码器、胶粘接头、电池、线束  
- 不确定回火温度的薄壁 7075、有预应力的弹簧  

6061-T6 在常见喷粉固化下一般还能用，但结构件若另有热处理状态，炉温上限写进工艺，不要默认。

压铸件气孔里的气遇热会鼓泡。喷粉前要烘透或浸渗；样机 CNC 件没有这个问题，开模件才爆。见 [压铸](../die-cast.md)。

## 顺序

```text
要接地又要外观
  → 导电氧化或局部保护出金属，再喷涂；接地凸台全程保护

钢件喷漆
  → 磷化或底漆，不要发黑完再喷（油膜和漆打架）

铝件外观外壳
  → 喷粉为主；装饰阳极不耐磕的大平面罩也可以喷粉
```

喷粉盖在阳极上要单独做附着力，不要假设「阳极更糙所以更粘」。

## 选型必须冻结

- [ ] 喷粉 / 喷漆 / 电泳；户内还是户外  
- [ ] RAL 或色板、光泽（平光/桔纹）  
- [ ] 膜厚范围  
- [ ] 保护：螺纹、止口、密封面、接地、连接器孔  
- [ ] 内腔要不要膜（防锈盒要写）  
- [ ] 最高固化温度；是否允许已压 PEM  
- [ ] 附着力、盐雾只写图纸上真的要检的  

## 验收

- [ ] 对色板；外表面无露底、流挂、颗粒、缩孔  
- [ ] 膜厚抽检（大面和边角）  
- [ ] 螺纹通规、止口能装  
- [ ] 接地面导通  
- [ ] 压铸件无鼓泡  

Fail：螺纹喷死、接地被盖、色号口头「跟上次差不多」、内腔完全没有膜但盒要防锈。

## 坑

- 喷粉绝缘了钣金接地点。见 [钣金](../sheet-metal/README.md)。  
- 膜厚把铰链和盖间隙吃掉。  
- 塑料件按金属喷粉温度去烤，变形。  
- 交期不含喷涂排队和做夹具保护。
