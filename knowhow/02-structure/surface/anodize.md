# 阳极氧化

**大类：** [结构件](../README.md) · **小类：** [表面处理](./README.md)

铝（及少数镁、钛）在电解槽里长出氧化膜。机器人结构里三件不要混写成「阳极」：

| | **普通阳极** | **硬质阳极** | **导电氧化** |
|---|---|---|---|
| 实质 | 硫酸阳极，染色后封孔 | 低温、厚膜、硬 | **不是阳极**。铬酸盐/无铬转化膜，很薄 |
| 膜厚口头 | 约 5–15 μm，外观件常按 8–12 μm 冻 | 约 25–50 μm | 约 1 μm 级 |
| 外观 | 本色、黑、可染色 | 灰褐到深灰，染不了鲜艳黑 | 黄、彩、本色，无装饰光泽 |
| 电 | **绝缘** | 更绝缘 | **导电**，可接地 |
| 尺寸 | 孔缩小、外圆变大 | 更明显，精密孔常处理前留量或处理后修 | 配合尺寸一般不用改 |
| 用途 | 6061 关节座、外观法兰 | 滑轨、销孔、耐磨面 | 屏蔽盒、喷漆打底、要接地的铝件 |

硬质阳极的硬度在膜上，基材还是铝。它不替代钢，也不替代轴承。

## 尺寸怎么变

氧化膜大约一半长进基材、一半长出来。口头估算（以工艺试样为准，不要拿去替代检具）：

```text
外圆直径大约增大 1 × 膜厚
孔直径大约减小 1 × 膜厚
```

例：膜厚 10 μm，φ20 H7 孔若按成品标注又整孔阳极，孔径大约小 0.01 mm，配合直接变紧。螺纹、轴承室、销孔、密封圈槽默认 **保护**（塞子、胶、或局部不处理）。M3 以下螺纹阳极后更容易失效。

图纸写清：膜厚、保护部位、关键尺寸是处理前还是处理后。只写「阳极发黑」厂按最便宜的普通阳极做。

## 材料和颜色

- **6061：** 装饰阳极最稳，黑色也比较匀。  
- **7075：** 可以阳极，颜色容易发灰、发花，不要和 6061 要求同一块色板。  
- **压铸铝（ADC12 等）：** 硅高，装饰阳极发灰发花。要外观走 [喷涂](./coating.md)。  
- **2 系（含铜多）：** 膜薄、易花，精密外观少用。  

黑色来自染色，不是膜本身是黑的。不封孔会掉色、手印、盐雾差。封孔后再机加会把膜磨掉，露白。

同一件上「外观黑阳极 + 接地面导电」必须划区域。整件阳极再想用螺钉牙刮开接地，批量不稳定。

## 选型必须冻结

- [ ] 普通 / 硬质 / 导电氧化；标准或膜厚范围  
- [ ] 颜色与封孔（黑阳极写封孔）  
- [ ] 保护：螺纹、轴承室、配合孔、接地凸台  
- [ ] 硬质阳极后还要不要研磨销孔  
- [ ] 导电氧化要不要无铬（RoHS）；和喷漆的顺序  
- [ ] 挂具点允许留在哪个非外观面  

## 验收

- [ ] 色差对色板；黑阳极无大面积露白、烧焦  
- [ ] 膜厚抽检（外观面和关键面）  
- [ ] 螺纹通止规；轴承室、销孔塞规  
- [ ] 接地面电阻（要求导电的面）  
- [ ] 盐雾只在图纸写了才检，不要口头「要过 96 h」  

Fail：精密孔未保护、硬氧当普通氧、压铸件阳极发花当来料不良、封孔前就包装互相染色。

## 坑

- 6061 图纸，厂用杂铝，阳极发灰。  
- 硬质阳极不保护销孔，装配铰孔把膜打穿。  
- 屏蔽壳体整件绝缘阳极，EMC 返工刮漆。  
- 阳极排队没进交期。
