# 3D 打印

**大类：** [结构件](./README.md)

## 1. 是什么

FDM / SLA / SLS / MJF 等增材。默认用途：工装、检具、线卡、装配干涉检查。

**不作为承力结构量产路径。** 临时装机必须标明材料、填充、限制工况，G4 按工装件放行。

## 2. 在机器人里干什么

走线验证、手板外观、夹具。不替代 CNC 关节座。

## 3. 选型必须冻结

- [ ] 工艺与材料
- [ ] 是否承力、是否靠近热源或电池
- [ ] 公差预期（不要按 CNC 验收）

## 4. 配套关系

手板尺寸未补偿 shrinkage，拿去「验证孔位」会误导开 CNC。

## 5. 验收要点

材料标识、明显变形、螺纹是否用预埋件。

## 6. 已知坑

- 树脂件当承力支架，温升后蠕变。
- 打印螺纹直接当结构连接，几次拆装就滑。
