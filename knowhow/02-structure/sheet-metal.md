# 钣金

**大类：** [结构件](./README.md)

## 1. 是什么

板材激光/冲压 + 折弯，可选焊接、铆接、PEM 螺母。折弯累积误差比单件 CNC 大，接口孔必须按装配定义。

## 2. 在机器人里干什么

电池盒、算力盒、防护罩、轻载支架。不默认当关节承力件。

## 3. 选型必须冻结

- [ ] 板材牌号与厚度
- [ ] 折弯半径、孔到边距离
- [ ] 焊接 / 铆接 / PEM 规格
- [ ] 表面处理（喷粉色号、导电氧化）
- [ ] 与机加件、接插件的避让

## 4. 配套关系

要展开图还是 3D 钣金特征，和厂约定一种。喷粉后螺纹孔必须保护。

## 5. 验收要点

板厚、孔位、折弯角度、平面度抽检；喷粉后螺纹通规。

## 6. 已知坑

- 三维能装，折弯后螺母柱碰到电芯。
- 喷粉绝缘了本应接地的点。
- 没有展开图版本号，厂用旧 DXF。
- 按 CNC 公差要求钣金，报价和交期一起爆。
