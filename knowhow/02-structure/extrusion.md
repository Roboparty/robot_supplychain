# 型材

**大类：** [结构件](./README.md)

## 1. 是什么

挤出铝型材切长、打孔、装角件。改长度快，刚度与孔系精度不如 CNC 关节座。

## 2. 在机器人里干什么

腿/臂 Link 的快速验证、机架、线槽。量产人形若继续用工业型材，要单独评外观、疲劳和连接刚度。

## 3. 选型必须冻结

- [ ] 截面型号、合金与状态
- [ ] 切断长度公差、孔位图纸版本
- [ ] 连接：螺栓角件 vs 焊接 vs 嵌入 CNC 接头
- [ ] 表面：阳极还是原色

## 4. 配套关系

两端接头往往是 CNC 件。型材槽孔与接头销的配合要冻，不能现场钻。

## 5. 验收要点

截面、长度、孔距、切口垂直度。

## 6. 已知坑

- 按「某宝同型号」混批，槽宽不同，角件装不上。
- 孔位口头改，旧料与新接头混用。
