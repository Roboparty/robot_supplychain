# 表面处理

**大类：** [结构件](./README.md)

## 1. 是什么

阳极、喷粉、电泳、电镀、钝化、热处理等。常常是机加/钣金之后的 **二次外发**，必须单独写入交期。

## 2. 在机器人里干什么

防腐、绝缘或导电、外观、硬度。导电氧化 vs 绝缘阳极选错，接地和屏蔽会一起错。

## 3. 选型必须冻结

- [ ] 工艺、色号、膜厚
- [ ] 哪些面导电、哪些面绝缘
- [ ] 哪些孔要保护（螺纹、配合孔）
- [ ] 处理后是否还要检尺寸

## 4. 配套关系

与机加厂约定加工顺序和测量节点，避免「谁的尺寸责任」扯皮。

## 5. 验收要点

色差、膜厚抽检、螺纹通止、配合孔。

## 6. 已知坑

- 阳极后尺寸超差，配合装不上。
- 螺纹喷死。
- 交期只算机加 7 天，阳极排队另算。
