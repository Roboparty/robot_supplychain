# 钣金

**大类：** [结构件](../README.md)

板材切断再折弯，必要时焊、铆、压铆。样机盒体、支架、防护罩的默认做法。折弯误差会累积，**不能按 CNC 的孔距和平面度验收**。

| 页 | 讲什么 |
|---|---|
| [折弯与展开](./bend.md) | 激光/冲压、折弯半径、孔到折弯、K 因子、公差 |
| [板材](./material.md) | 5052、6061 板、冷轧钢、镀锌、304；厚度 |
| [连接](./joining.md) | 压铆 PEM、拉铆、抽芯铆钉、点焊、满焊 |

关节承力法兰、轴承室走 [CNC](../cnc.md)。外形复杂又要量产的壳体再谈 [压铸](../die-cast.md)。

## 在机器人里干什么

电池盒、算力盒、驱动器罩、轻载支架、线槽盖。承力只做到「盒体不塌、支架不晃」。髋膝主结构不要用折弯件当唯一传力路径。

## 选型必须冻结

- [ ] 牌号 + 状态 + **板厚**（1.5 mm 不是「1.5 左右」）。见 [板材](./material.md)  
- [ ] 内折弯半径、折弯方向、哪些边要折弯让位  
- [ ] 关键孔相对哪条基准，而不是相对一连串折弯边  
- [ ] 主文件是 3D 还是展开 DXF，以及版本号  
- [ ] 连接：压铆型号 / 拉铆 / 焊。见 [连接](./joining.md)  
- [ ] 表面处理与接地保护。见 [喷涂](../surface/coating.md)、[阳极](../surface/anodize.md)  
- [ ] 和机加件、电芯、接插件的间隙（按折弯累积，不按理想 3D）  

## 配套

- **展开：** 同一 3D 在两家厂的展开长度可以差零点几毫米。约定厂按 3D 出展开，或锁定一家的 K。不要把 A 厂 DXF 丢给 B 厂还要求孔距不变。  
- **表面：** 先折弯再做表面。喷粉会吃间隙、盖住接地。  
- **线束：** 过孔和接头开孔按 [插头外壳](../../03-electronics/connectors/xt30.md) 留量，喷粉后再通规。  

## 一句话坑

按 CNC ±0.05 去标钣金，报价和交期一起爆；折弯后螺母柱碰到电芯；喷粉把接地点盖住；DXF 没有版本，厂用旧展开。
