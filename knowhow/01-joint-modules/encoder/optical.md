# 光电编码器

**大类：** [关节模组](../README.md) · **小类：** [编码器](./README.md)

用光读码盘上的刻线。发光管照到码盘，接收管看透射或反射回来的明暗，换成角度。口头也叫光编。精度档通常高于 [磁编](./magnetic.md) 和 [电感编](./inductive.md)，代价是光路怕油、怕尘、怕冲击。

关节油脂和扁平空间装不下干净光路时，不要为了「光编精度高」硬换。输出端要绝对角、又要中空、旁边是无框电机时，先看电感编。

## 两种光路

| | **透射** | **反射** |
|---|---|---|
| 读头 | 发光和接收分居码盘两侧 | 发光和接收在同一侧 |
| 码盘 | 玻璃或金属，刻线透光 | 盘面或环面刻反射码 |
| 轴向 | 两侧都要空间，关节里偏厚 | **更薄**，输出法兰相对好摆 |
| 中空 | 大通孔别扭 | 有环形读头，光路仍要密封 |

码盘材料：玻璃刻线细、光学好，摔和冲击会裂；金属盘抗冲击，刻线密度通常低一档。物流和装配跌落对玻璃盘是来料项，不是上机才发现的问题。

## 增量和绝对

- **增量：** 一圈两条正交刻线（A/B）加一条零位（Z）。分辨率靠刻线数再加电子细分。上电没有绝对角，要转到 Z 或限位才知道在哪。人形不许甩腿找零时，不要用增量光编当关节侧唯一反馈。
- **绝对：** 多码道或伪随机码，上电即有单圈角。多圈还要电池、齿轮记圈，或另算。掉电期间被人扳关节，纯单圈绝对会丢圈。

样本上的 bit 经常是 **刻线经细分后的分辨率**。细分把一格切得更细，刻线误差、偏心、码盘端面跳动还在。分辨率和精度两个数一起冻。

## 和磁编、电感编

| | 磁编 | 电感编 | 光编 |
|---|---|---|---|
| 读什么 | 磁铁方向 | 线圈对金属靶的耦合 | 码盘刻线的明暗 |
| 怕什么 | 电机漏磁、附近钢件 | 气隙、同心、金属屑 | **油雾、粉尘、凝露、冲击（玻璃盘）** |
| 关节默认 | 电机侧换向 | 输出侧、要中空、旁边是无框电机 | 光路能单独密封、精度预算更紧的输出端 |

谐波、行星仓里的脂不能进光路。光编要有自己的密封腔，不和柔轮、齿面共用油脂空间。密封做不到，桌面上的精度上机几天就丢脉冲。

## 冻结清单

- [ ] 透射还是反射；码盘玻璃还是金属
- [ ] 增量还是绝对；单圈还是多圈；上电是否允许找 Z
- [ ] 分辨率、细分倍数、精度、重复精度
- [ ] 允许偏心、气隙、轴向窜动
- [ ] 是否中空；密封是否与减速器油脂隔离
- [ ] 抗冲击 / 玻璃盘运输与装配要求
- [ ] 协议、供电、更新率

## 验收

- 洁净装配后测满圈；再在带脂关节里跑一段时间复测丢脉冲
- 多次上电零点（绝对式）
- 玻璃盘：来料外观、轻敲后满圈是否出现固定缺角
- 温升后看凝露、信号幅度
- 增量式：找 Z 的行程是否允许上机做

## 已知坑

- 把细分后的 bit 数写进末端误差预算。
- 光编装进开式谐波，脂雾上去，样本精度作废。
- 玻璃码盘物流摔过，通电仍有数，满圈缺一截。
- 增量光编当关节绝对反馈，上电必须甩腿找零。
- 只因精度高换掉电感编，扁平关节里没有密封腔，维护比精度先爆。
