**大类：** [关节模组](../README.md)

旋变耐温耐振，工业伺服多，人形少。本页不展开。

再分：**增量式** vs **绝对式**（单圈 / 多圈）。人形上电若不允许甩腿找零，关节侧通常要绝对式。

## 在机器人里干什么

- **电机侧：** 换向、电流环、速度环。电角度 = 机械角 × 极对数，分辨率不够会抖，见 [槽极](../frameless-motor/slot-pole.md)。
- **关节 / 输出侧：** 减速器之后的真实关节角，把回差、柔轮变形留在测量里，而不是留在末端误差里。

减速机或一体化模组里常已焊死编码器。下单先问是单编、真双编还是伪双编，再问磁编、电感编还是光编。见 [count.md](./count.md)。

## 选型必须冻结

- [ ] 几路、装在哪：单编 / 真双编 / 伪双编（见 [count.md](./count.md)）
- [ ] 原理：磁编 / 电感编 / 光电 / 旋变
- [ ] 绝对 / 增量，单圈 / 多圈，上电是否允许运动找零
- [ ] 分辨率 vs 精度（两个数，别混）
- [ ] 协议：ABZ / SSI / BiSS / 私有串行；驱动固件是否原生支持
- [ ] 供电、线长、屏蔽、接插件
- [ ] 机械：实心 / 空心、对中、允许偏心与轴向间隙
- [ ] 环境：油雾（光编必问密封）、电机漏磁（磁编必问）

## 配套关系

- **驱动：** 协议、供电、单编还是双编通道，必须和 [驱动器](../driver.md) 对上。
- **结构：** 偏心和端面跳动会把精度吃光，安装面是结构件公差。
- **减速：** 只有关节侧编码才反映输出角；只用电机侧等于把回差让给控制。

## 验收要点

- 上电枚举、绝对位置是否重复（多次上电对比）
- 慢速旋转看跳码、丢脉冲
- 线序与屏蔽
- 装配后满圈误差（有条件上简易转台）
- 伪双编：协议里的「关节角」在卡住输出、只转电机时是否还在变

## 已知坑

- 分辨率够、安装偏心，精度仍然差。
- 磁编贴在漏磁严重的无框电机旁，零点漂。见 [magnetic.md](./magnetic.md)。
- 协议口头「都能接」，驱动固件没有这款芯片。
- 样本写双编，拆开只有一颗芯片，关节角是电机角除以减速比。见 [count.md](./count.md)。
- 只买电机侧编码，谐波空程/柔轮变形全进末端重复精度。见 [谐波额定](../reducer/harmonic/ratings.md)。
