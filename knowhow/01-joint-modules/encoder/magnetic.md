# 磁编码器

**大类：** [关节模组](../README.md) · **小类：** [编码器](./README.md)

用一块磁铁的磁场方向代表角度。芯片是霍尔、TMR 或 AMR，输出绝对单圈角度（再加索引或电池才是多圈）。关节里 **电机侧换向** 最常用磁编：小、便宜、耐油。

装在输出端也可以，但无框电机漏磁会拉零点。漏磁重的输出端优先谈 [电感编](./inductive.md)。

## 两种摆法

| | **轴端（on-axis）** | **离轴（off-axis）** |
|---|---|---|
| 磁铁 | 直径向充磁的圆片，贴在轴端面 | 径向充磁的磁环，套在轴上 |
| 芯片 | 对着磁铁圆心 | 在磁环外侧或端面读 |
| 中空 | 轴端被磁铁挡住，走线别扭 | **可以中空** |
| 关节里 | 实心电机轴尾 | 关节输出、要过线的法兰 |

气隙、偏心、磁铁牌号和充磁均匀性直接进精度。样本上的 bit 数是 **分辨率**（把一圈切成多少份），不是装配后的 **精度**（和真值差多少角秒）。两个数一起冻。

## 和电机漏磁

无框力矩电机的磁钢就在旁边。外磁场叠到编码磁铁上，零点漂、噪声变大，严重时角度跳变。

- 电机侧：芯片和编码磁铁离转子磁钢要有距离或导磁屏蔽，按厂家安装图，不要自行把芯片贴到定子端部。
- 输出侧：谐波/行星输出法兰外的磁编，仍可能吃到电机轴向漏磁，尤其扁平关节。
- 附近钢件、螺钉、轴承也会弯磁路。安装面材料要问。

霍尔换向是另一套粗磁传感器，不做 FOC 主反馈。见 [hall.md](../frameless-motor/hall.md)。

## 冻结清单

- [ ] 轴端还是离轴；是否必须中空
- [ ] 分辨率、精度、重复精度；最高转速和带宽
- [ ] 磁铁是芯片厂配套还是自备；充磁方向与气隙
- [ ] 绝对单圈还是多圈；多圈掉电能不能保持
- [ ] 协议与供电
- [ ] 离电机磁钢的距离、要不要屏蔽
- [ ] 允许偏心、轴向窜动

## 验收

- 装进真实关节（带电机磁钢）后再看零点，不要只在桌面上转磁铁
- 多次上电、温升后零点是否漂
- 满圈误差；靠近定子端部时有无跳变
- 油雾/脂不要求光电那种洁净，但磁铁锈蚀和胶层进气隙要看

## 已知坑

- 把 17 bit 分辨率当成 17 bit 精度写进误差预算。
- 磁编贴在无框电机漏磁区，桌面正常、装进关节零点漂。
- 换一家磁铁，外径一样、充磁强度不同，芯片饱和或信号太弱。
- 输出端磁编当真双编的关节反馈，扁平模组里其实在读电机漏磁。
