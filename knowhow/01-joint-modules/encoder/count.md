# 单编、双编、伪双编

**大类：** [关节模组](../README.md) · **小类：** [编码器](./README.md)

「几路编码」说的是 **有几路独立测角**，不是协议里报了几个角度字段。磁编、电感编还是光编是另一刀，见 [magnetic.md](./magnetic.md)、[inductive.md](./inductive.md)、[optical.md](./optical.md)。

```text
单编          只测一处：电机轴，或输出法兰
真双编        电机轴一路 + 减速器输出一路，两路都闭环
伪双编        只测电机轴；「关节角」= 电机角 / 减速比（或只在上电用粗绝对对一下零）
```

## 单编

只有一颗传感，装在 **电机侧** 或 **输出侧** 其中一处。

| 装在哪 | 换向 / 电流环 | 末端真实角 | 何时够用 |
|---|---|---|---|
| **电机侧** | 好做。电角直接乘极对数 | **没有**。回差、柔轮扭转变形、行星齿隙全部变成末端误差 | 位置精度不抠、或减速器回差已经很小且接受它 |
| **输出侧** | 差。回差夹在电机和测点之间，低速换向抖；分辨率还要再除以减速比才够一个电周期 | 直接是关节角 | 几乎不单独当 FOC 主反馈 |

人形关节默认不要「只有输出编、没有电机编」去跑 FOC。电机侧没有编码时，至少要霍尔做换向冗余，见 [霍尔](../frameless-motor/hall.md)。

单编电机侧的关节角是算出来的：`θ_关节 ≈ θ_电机 / i`。谐波空程和柔轮变形不会出现在这个数里，示教重复精度会比协议角度差。

## 真双编

两颗独立传感器：

- **电机侧：** 高速、电角度、电流环 / 速度环。
- **输出侧：** 减速之后的关节绝对角，外环位置和力控用这路。

外环用输出角，内环仍用电机角。回差变成两路读数之差，可以观测，也可以在控制里补偿，但 **补偿表不是第二颗编码器**。

代价：多一路供电和协议、多一套安装公差、两个零点要一起标定（方向、减速比是否整数、上电多圈是否对齐）。驱动必须有两个编码器口，见 [驱动器](../driver.md)。

力控、阻抗、上电不许找零运动、要发现减速器打滑时，谈真双编。输出侧中空走线时，电感环形编码器比轴端磁编好摆，见 [inductive.md](./inductive.md)。

## 伪双编

协议或样本写「双编码器 / 电机角 + 关节角」，硬件上 **输出端没有独立测角**，关节角由电机侧读数除以减速比得到。

变体，采购都要拆开问：

| 叫法里可能是 | 实际上 |
|---|---|
| 双角度上报 | 一颗电机编，固件里 `θ_out = θ_m / i` |
| 输出端「也有编码」 | 输出端只有几位粗绝对或一颗霍尔，**只在上电扇区对零**，运行中外环仍跟电机编 |
| 多圈绝对 | 没有电池多圈芯片，圈数是软件按减速比累加的；断电期间被人扳关节会丢圈 |

伪双编不是不能用：成本、走线、轴向都比真双编省，位置模式在回差可接受时够用。不能把它的关节角当成谐波输出端的实测角，也不能当成减速器打滑检测。

判定：卡住输出法兰，只让电机在齿隙里微动。真双编的输出读数基本不动；伪双编的「关节角」会跟着电机角变。

## 冻结清单

- [ ] 单编 / 真双编 / 伪双编；各路装在电机轴还是输出法兰
- [ ] 每路是绝对还是增量；谁做 FOC，谁做外环
- [ ] 伪双编要写明：关节角是除法，还是上电粗绝对 + 运行中单编
- [ ] 减速比是否参与换算；比不是整数时多圈怎么对齐
- [ ] 两个零点的标定流程（真双编）
- [ ] 驱动通道数与协议

## 已知坑

- 样本「双编」不写芯片颗数，到货是伪双编，力控外环跟的是齿隙。
- 只标定电机零点，输出零点差一截，上电姿态歪。
- 输出侧增量编当绝对用，断电被搬动后静默错一圈。
- 用电机侧单编除以减速比验收末端重复精度，和打表结果对不上还怪结构。
