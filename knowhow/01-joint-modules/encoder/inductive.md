# 电感编码器

**大类：** [关节模组](../README.md) · **小类：** [编码器](./README.md)

定子是一圈 PCB 线圈（激励 + 接收），转子是带齿或带叶的金属靶。激励线圈产生交变磁场，靶的角度改变接收线圈的耦合，芯片算出绝对角。

**没有编码磁铁**，所以不怕无框电机漏磁。这是它相对 [磁编](./magnetic.md) 装在关节输出端的主要理由。油污和粉尘也比 [光编](./optical.md) 好扛。

## 结构

```text
        金属靶（随轴转，常做成环，中间可中空）
              ↕ 气隙
        线圈 PCB（固定在壳体）
```

中空是天然形态：靶和 PCB 都是环，线从圆心过。谐波输出、行星输出法兰上常见。电机轴尾的小空间通常仍用磁编，不必上电感编。

精度靠气隙、同心和靶的齿形，不靠「有没有磁铁」。偏心和 PCB 翘曲会变成周期误差。分辨率同样不等于精度。

带宽和延迟要单独问。力控外环如果吃这路角度，分组延迟会进阻尼；样本只写 bit 数不够。

## 和磁编怎么选

| | 磁编 | 电感编 |
|---|---|---|
| 怕什么 | 电机漏磁、附近钢件、磁铁气隙 | 气隙/同心、金属屑改变靶、强电磁干扰要问 |
| 中空 | 离轴磁环可以，轴端磁铁不行 | **环形，适合走线** |
| 体积 / 成本 | 小、便宜，电机侧默认 | 通常更大、更贵 |
| 关节默认 | 电机侧换向 | 输出侧真双编、漏磁重的位置 |

[光编](./optical.md) 精度可以更高，但关节油脂和冲击下维护差，光路要单独密封。输出端在「要绝对角 + 要中空 + 旁边是无框电机」时，电感编是短名单，不是磁编的便宜替代。

## 冻结清单

- [ ] 中空孔径、PCB 外径、允许气隙和偏心
- [ ] 分辨率、精度、重复精度、延迟 / 更新率
- [ ] 绝对单圈还是多圈；协议与供电
- [ ] 靶是厂家成套还是只卖 PCB（自做靶等于自做编码器）
- [ ] 安装面：铝壳体涡流、螺钉是否进入线圈区
- [ ] 和电机动力线并行时的屏蔽

## 验收

- 按图纸气隙装配后再测，手捏气隙不算数
- 满圈误差、重复上电
- 电机通额定电流、转子转到最近位置时，角度是否被干扰（电感编的卖点就在这里，要在整机上证）
- 协议延迟是否满足外环周期

## 已知坑

- 当磁编的「抗油版」买，不核中空和延迟，力控外环用不上。
- 只买读数头，靶自己车，齿形和材料不对，精度全部作废。
- 安装螺钉或轴承压进线圈区，周期误差像偏心。
- 样本在洁净台架上的精度，装进带脂谐波后没有复测。
