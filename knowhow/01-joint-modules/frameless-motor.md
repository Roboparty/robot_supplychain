# 无框力矩电机

**大类：** [关节模组](./README.md)

## 1. 是什么

只提供 **定子 + 转子**（有时含霍尔），没有壳体、轴承、编码器。关节厂把它套进自己的轴承和减速器结构里，换来薄、中空、高扭矩密度。

也有带壳的盘式/力矩电机，选型逻辑相近，但安装接口不同。

## 2. 在机器人里干什么

一体化关节的「肌肉」。谐波/摆线的输入侧，或准直驱关节的唯一转矩源。

不替代：编码器、轴承、驱动器——这些要另配或买成套模组。

## 3. 选型必须冻结

- [ ] 额定 / 峰值扭矩、额定转速、电压与 Kv / Kt
- [ ] 外径、内径（中空）、轴向长度、重量
- [ ] 极槽配合、齿槽转矩、转矩波动
- [ ] 绕组接法、线规、温升与绝缘等级
- [ ] 磁钢牌号与最高工作温度
- [ ] 安装：定子止口、转子与波发生器/轴的过盈或螺钉
- [ ] 是否提供霍尔、温度传感器、线长与出线方向

## 4. 配套关系

- **减速机：** 峰值扭矩 × 减速比不能打爆柔轮/针齿；最高转速不能超减速机输入限速。
- **编码：** 极对数要和编码器分辨率、驱动换向策略匹配。
- **驱动：** 电流、母线电压、电流环带宽；弱磁是否允许。
- **结构：** 气隙均匀靠机加工；定子胶接/过盈工艺要写进作业指导。

## 5. 验收要点

- 外形与中空、线长
- 直流电阻、绝缘、反电势波形（抽检）
- 装配后齿槽转矩、异响、温升
- 磁钢是否有崩裂、锈蚀（来料外观）

## 6. 已知坑

- 只看峰值扭矩，持续转矩和温升不够，行走十分钟降功率。
- 气隙不均当「驱动调不好」。
- 转子与谐波波发生器同轴差，谐波寿命和噪音一起坏。
- 线出方向与关节壳体干涉，现场剪线破坏绝缘。
