# 编码器

**大类：** [关节模组](./README.md)

## 1. 是什么

把角度变成数字。关节里常见：

| 类型 | 特点 | 典型用法 |
|---|---|---|
| 磁编码器 | 抗油污、体积小、精度中 | 电机换向、很多一体化关节 |
| 光电编码器 | 精度高、怕尘和冲击 | 高精度关节侧 |
| 旋变 | 耐温耐振、模拟/解码 | 工业伺服；人形较少但能用 |

再分：**增量式** vs **绝对式**（单圈 / 多圈）。人形上电若不允许甩腿找零，关节侧通常要绝对式。

## 2. 在机器人里干什么

- **电机侧：** 换向、电流环、速度环。
- **关节 / 输出侧：** 真实关节角，吃掉减速器回差。双编码器是力控和零位的常见做法。

减速机内部有时已集成输出端编码，买模组时要问清是单编还是双编。

## 3. 选型必须冻结

- [ ] 安装位置：电机侧 / 关节侧 / 双编
- [ ] 绝对 / 增量，单圈 / 多圈，上电是否允许运动找零
- [ ] 分辨率 vs 精度（两个数，别混）
- [ ] 协议：ABZ / SSI / BISS / 私有串行
- [ ] 供电、线长、屏蔽、接插件
- [ ] 机械：空心轴 / 轴套、对中公差、允许偏心与跳动
- [ ] 环境：油雾、磁场（磁编靠近电机漏磁要评估）

## 4. 配套关系

- **驱动：** 协议和供电必须驱动器原生支持或有明确转接板。
- **结构：** 偏心和端面跳动会把精度吃光，安装面是结构件公差。
- **减速：** 关节侧编码才反映输出角；只用电机侧编码等于把回差让给控制。

## 5. 验收要点

- 上电枚举、绝对位置是否重复（多次上电对比）
- 慢速旋转看跳码、丢脉冲
- 线序与屏蔽
- 装配后满圈误差（有条件上简易转台）

## 6. 已知坑

- 分辨率够、安装偏心，精度仍然差。
- 磁编贴在漏磁严重的无框电机旁，零点漂。
- 协议口头「都能接」，驱动固件没有这款芯片。
- 只买电机侧编码，谐波回差全进末端重复精度。
