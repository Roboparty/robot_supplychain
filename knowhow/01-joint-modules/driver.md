# 驱动器

**大类：** [关节模组](./README.md)

## 1. 是什么

把母线电能变成电机三相电流，并跑电流环（常还有速度/位置环）。形态：

- **外置驱动柜 / 单轴模块：** 调试方便，走线重，不适合全身几十轴量产形态。
- **关节内驱：** 和电机、编码做成模组，省线，热和维修是代价。
- **多轴底板：** 几轴驱动打在一块板，放躯干。

## 2. 在机器人里干什么

全身运动控制的执行层。总线周期、电流环带宽、再生制动、保护策略，决定能不能跟上规划、会不会一摔就烧。

## 3. 选型必须冻结

- [ ] 母线电压、持续 / 峰值电流（对应该电机）
- [ ] 电流环带宽、PWM 频率、采样
- [ ] 总线：CAN / EtherCAT / 私有，周期（如 1 ms / 250 µs）
- [ ] 编码器接口种类与数量（单编 / 双编）
- [ ] 抱闸输出、STO / 安全转矩关断是否需要
- [ ] 再生与制动电阻策略
- [ ] 散热：自然 / 壳体导热；关节内驱的温升预算
- [ ] 固件：位置/力矩模式、阻抗、开源程度、上位机

## 4. 配套关系

- **电机：** 电流、电压、极对数、电感电阻；弱磁表。
- **编码：** 见 [encoder.md](./encoder.md)。
- **电气：** 母线电容、预充、整机接地；多轴同时峰值会把电源打崩。
- **结构：** 内驱要规定导热面和灌胶/导热垫。

## 5. 验收要点

- 枚举、总线掉线恢复
- 电流环阶跃、限流保护是否动作
- 编码器读数方向与机械正方向
- 过温、过流、欠压保护抽检（按安全规程）

## 6. 已知坑

- 单轴样品能转，全身峰值同时出现时电源和驱动一起保护。
- 固件分支：样品一套、小批一套，力控参数全失效。
- 没有抱闸驱动电路，断电膝关节砸地。
- 协议周期对不上全身调度，看起来「电机慢」。
