# 一体化关节模组

**大类：** [关节模组](./README.md)

## 1. 是什么

把 [减速机](./reducer/README.md)、[无框电机](./frameless-motor/README.md)（须标明内转子或外转子）、[编码器](./encoder.md)、[驱动器](./driver.md)，以及可选的 [抱闸](./brake.md) / 关节力矩传感器，做成 **一个可采购、可换修的单元**。对外只谈：法兰、电缆、协议、扭矩曲线、重量。

这是产品形态，不是第四种减速原理。内部仍是谐波或行星或摆线。

## 2. 在机器人里干什么

早期样机的默认买法：少掉自组公差和驱动匹配。代价是：协议绑定、维修换整只、独家风险。

## 3. 选型必须冻结

- [ ] 内部减速类型（谐波 / 行星 / 摆线）——影响冲击和厚度
- [ ] 内部电机是内转子还是外转子
- [ ] 额定 / 峰值扭矩、转速、重量、外径、中空、出线
- [ ] 电压与总线协议、控制周期、力矩模式是否开放
- [ ] 单编码器还是双编码器
- [ ] 抱闸有无、力觉有无
- [ ] 电缆与接插件、IP 防护
- [ ] 台架验收口径：空程、温升、噪音、通讯掉线
- [ ] 固件版本、上位机、故障码文档
- [ ] 返修路径与备件（整模组 vs 可换电缆/闸）

## 4. 配套关系

全身电压平台、总线、法兰尽量少种类。同一厂商不同扭矩档，优先同一协议同一出线定义。

结构侧：连杆惯量、弯矩要按 **模组输出轴承许用** 校核，不是按电机峰值去乘减速比瞎算。

## 5. 验收要点

来料：外观、序列号、通电枚举、空载运动、异常噪音、抱闸。  
小批：抽台架曲线，和样品固件对比。

Conditional 不得用于承力关键轴，除非会签并限批次。

## 6. 已知坑

- 样本扭矩是电机峰值×减速比，没扣效率、温升和轴承弯矩。
- 样品固件与量产固件不是同一分支。
- 机械能装、SDK 周期对不上全身调度。
- 无第二来源，交期一跳整机停。
