# 制动器（抱闸）

**大类：** [关节模组](./README.md)

## 1. 是什么

关节里多用 **电磁断电制动**：没电时弹簧压闸，有电时松开。用来断电保持姿态、防止髋膝坠落，不是用来当行走中的主刹车。

## 2. 在机器人里干什么

髋、膝、有时肩。腕、小关节常常不加，靠减速自锁或机械限位——必须在 G0 写死哪些轴有闸。

## 3. 选型必须冻结

- [ ] 保持力矩（相对该轴峰值重力矩要有余量）
- [ ] 电压、保持功耗、吸合时间 / 释放时间
- [ ] 外形、中空、与电机/减速的轴向空间
- [ ] 摩擦片寿命、是否允许动态刹停（多数关节闸 **只允许静态保持**）
- [ ] 驱动器是否提供抱闸电源与互锁

## 4. 配套关系

驱动器掉电时序：先闸后电还是先电后闸，写进电气规范。结构要给闸的散热和磨屑留空间。

## 5. 验收要点

- 断电能刹住约定负载
- 通电能完全松开（残余摩擦会发热、毁减速器）
- 动作时间

## 6. 已知坑

- 闸没松开就使能电机，谐波和闸片一起磨。
- 保持力矩按「电机额定」选，没按连杆重力矩选，断电仍下滑。
- 功耗太大，关节内驱热预算被闸占满。
