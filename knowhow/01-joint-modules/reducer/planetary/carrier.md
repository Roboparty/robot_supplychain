# 行星架（笼式 / 悬臂）

**大类：** [关节模组](../../README.md) · **小类：** [减速机](../README.md) · **细分：** [行星减速机](./README.md)

行星架托着行星轮轴，多数关节减速机里它就是 **输出件**（接法兰）。齿系字母（NGW/NW）决定谁跟谁啮合，见 [types.md](./types.md)；**行星销怎么支撑** 是另一刀，决定倾覆刚度、轴承寿命和轴向能不能做薄。

减速比公式不因笼式/悬臂而变。变的是力怎么传到输出法兰、行星轮轴歪不歪。

## 两类怎么认

```text
悬臂式                          笼式（双侧支撑）
  输出法兰／盘                     前盘 ════ 柱／壁 ════ 后盘
       │                              │                 │
       └─ 销钉（一头悬空）              └─ 销钉两端都进孔 ─┘
            │                                   │
         行星轮                              行星轮
```

| | **悬臂式** | **笼式** |
|---|---|---|
| 结构 | 行星销只从 **一侧** 伸出，另一端自由或仅挡圈限位 | 两块端板（或一体笼）把销钉 **两端** 撑住，中间用立柱/周壁连成笼 |
| 销钉受力 | 悬臂梁：弯矩大、根部应力集中 | 简支梁：弯矩小、变形小 |
| 倾覆 / 弯矩 | 法兰一带径向力或倾覆，销钉先歪，齿面偏载 | 抗倾覆好，精密行星默认口径 |
| 轴向 | **可以更短** | 多一块端板 + 立柱，往往更厚 |
| 装配 | 简单，行星从开口侧套入 | 要过孔、压销、对相位；双联 NW 更烦 |
| 成本 / 工艺 | 便宜，铸造/机加一块盘就行 | 端板同轴、孔距公差严，贵 |
| 关节里 | 轻载、短时、轴向被卡死时才谈 | **协作 / 人形精密行星主路径** |

口头「一体式行星架」有时指笼式铸/机加一体，有时只是悬臂盘和法兰一体——下单写 **销钉单侧还是双侧支撑**，不要只写「一体」。

## 悬臂式

典型：输出法兰背面伸出 3～4 根销，行星轮轴承套在销上，靠挡圈或轴肩轴向限位。

- **优点：** 零件少、轴向短、开口一侧方便装行星和注脂。  
- **代价：** 负载经行星传到销根，再弯到法兰。倾覆力矩（连杆偏置、行走冲击）会让销钉外端张开，齿侧隙和噪音一起变。  
- **轴承：** 行星轮里常用滚针或薄壁球轴承，内外圈同时受弯，寿命按悬臂校，不能抄笼式样本曲线。  
- **适用：** 小扭矩腕指前级、单向负载、准直驱里扭矩不大且壳体帮你扛弯矩；或样机先验证齿比。  
- **不适用：** 髋膝输出、要小回差长期保持、法兰外伸很长的力臂。

坑：样本画成笼式照片，货是悬臂盘；倾覆刚度差一个数量级，控制振荡当「电机惯量不匹配」。

## 笼式

两块端板（输入侧一块、输出侧一块）用几根立柱或整圈壁连起来，行星销两端都进较孔/过盈孔。行星轮在两板之间转，像装在笼子里。

- **优点：** 销钉变形小 → 齿面接触好、均载稳、回差不易被架体弹性吃掉；法兰倾覆时力在笼里闭环。  
- **代价：** 轴向长度、重量、加工同轴；大修要拆笼。  
- **变体：**  
  - **分体笼：** 两盘 + 销/柱螺栓连接，可拆，孔系累计公差要管。  
  - **整体笼：** 一体铣出或铸造后精镗销孔，刚度和同轴更好，返修差。  
  - **带壁笼：** 周向封闭，刚度更好，润滑与散热要开孔。  
- **精密伺服行星**（关节模组里买到的 i=10～100 圆盒）多数是笼式或「准笼式」（输出盘 + 输入侧挡板双侧撑销）。

NW 双联行星轴更长，悬臂几乎必然抖；单级大比 NW **默认按笼式谈**。

## 和轴承、法兰、均载怎么咬

| 点 | 悬臂 | 笼 |
|---|---|---|
| 行星轴轴承寿命 | 按悬臂弯矩放大载荷 | 接近纯径向，可按样本 |
| 输出轴承 | 法兰轴承要额外扛倾覆 | 笼帮一部分，法兰轴承仍要校弯矩 |
| 均载 | 销一歪，三颗行星负载立刻偏 | 架刚时均载主要靠齿距精度和太阳浮动 |
| 中空走线 | 盘心好开孔 | 笼的输入侧板也要留孔，立柱别挡线 |

太阳轮浮动（均载常用手段）和行星架类型独立：笼式也可以浮动太阳；悬臂架再浮动，也补不回销钉刚度。

## 冻结清单

- [ ] 行星架：**悬臂 / 笼式**（销钉单侧还是双侧支撑）  
- [ ] 笼式：分体还是整体；立柱数；输入侧板是否参与支撑  
- [ ] 行星颗数、销径、销孔配合（过盈/胶/挡圈）  
- [ ] 输出法兰与架是否一体；许用弯矩 / 倾覆力矩（样本有没有单独给）  
- [ ] 行星轮轴承型号与润滑；高速时离心对悬臂销的额外校核  
- [ ] 中空孔径是否被输入侧挡板挡住  

## 验收

- 图纸或实物：销钉另一端有没有第二块板/座——没有就是悬臂  
- 空载盘动：悬臂常有「手感软」；上机前测扭转刚度和倾覆刚度（有条件）  
- 跑合后拆一颗行星：齿面是否单边亮（销歪偏载）  
- 同型号换供应商：架类型必须写进 IQC，不能只对齿比和回差档  

## 已知坑

- BOM 只写「行星减速机 i=20」，到货悬臂，按笼式刚度做控制增益。  
- 用悬臂架扛髋关节行走弯矩，行星销根疲劳断。  
- 笼式分体两盘螺栓预紧不够，振动后孔系松动，回差慢慢变大。  
- 把 RV 输出盘的「双侧曲柄支撑」和渐开线笼式行星架混成一个采购字段（RV 见 [摆线](../cycloidal/structure.md)）。  
- 为减轴向把笼式改成悬臂「只少一块板」，齿比不变，寿命和噪音全变。  

## 关节上怎么选

```text
协作臂 / 人形精密行星、要回差和刚度
  → 笼式（或厂商的双侧支撑等效结构）

轴向被壳体卡死、扭矩小、先验证速比
  → 可谈悬臂，但弯矩和寿命单独校，不要当量产默认

NW 双联、准直驱单级大比
  → 默认笼式；悬臂基本否决

供应商说「一体式」
  → 追问销钉几端支撑；画剖面确认
```
