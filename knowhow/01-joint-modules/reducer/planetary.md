# 行星减速机

**大类：** [关节模组](../README.md) · **小类：** [减速机](./README.md)

## 1. 是什么

太阳轮、行星轮、内齿圈组成的定轴/周转轮系。单级减速比通常不大（大约 3–10）
要 20–100 就 **多级串联**。齿制（直齿 / 斜齿）、轴承和箱体决定回差、噪音和刚度。

人形里常见：精密行星（低回差）或把行星做到关节模组里当一级减速。

## 2. 在机器人里干什么

需要 **效率高、转速能力强、成本相对可控** 的轴；也用于直线关节前级、轮式/腰部。大减速比时体积和级数上去，不一定比谐波更扁。

不替代：要极薄中空、回差极小的腕/肘，谐波往往更合适。

## 3. 选型必须冻结

- [ ] 级数与总减速比
- [ ] 额定 / 峰值输出扭矩、许用径向力和轴向力
- [ ] 回差（arcmin）与扭转刚度
- [ ] 效率、噪音、最高输入转速
- [ ] 输出形式：法兰、轴伸、空心
- [ ] 安装：输入轴与电机止口匹配，是否含适配法兰
- [ ] 润滑与安装方向（有的型号限制竖直/水平）

## 4. 配套关系

- **电机：** 止口、轴径、键/胀套；斜齿行星对电机轴轴向力要校核。
- **结构：** 多级行星轴向长度影响关节厚度，图纸要先占位。
- **控制：** 回差比谐波大时，关节侧编码器更必要。

## 5. 验收要点

- 减速比、回差等级与订单一致（同外形不同回差档是常见货）
- 空载噪音、漏脂
- 输出法兰跳动
- 样品与小批是否同一齿制（直改斜会改噪音和轴向力）

## 6. 已知坑

- 只看减速比，不看回差档，定位精度整轴被吃掉。
- 适配法兰私改，同轴差导致轴承早死。
- 当谐波的「便宜替代」用在薄壁中空关节，厚度超标、走线没孔。
