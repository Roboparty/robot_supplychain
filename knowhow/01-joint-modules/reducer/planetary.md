# 行星减速机

**大类：** [关节模组](../README.md) · **小类：** [减速机](./README.md)

伺服行星减速机的主流结构是 **NGW**：一个太阳轮、一组行星轮、一个内齿圈、一个行星架。功率由多颗行星轮分流，所以同扭矩下比平行轴齿轮箱更短、更同轴。单级减速比通常大约 3–10，要 20–100 就多级串联。

## 1. 是什么：四个构件

| 构件 | 位置 | 在减速机里通常干什么 |
|---|---|---|
| 太阳轮 | 中心，常与电机轴直联 | **输入** |
| 行星轮 | 太阳轮与齿圈之间，一般 3 颗（也可 4 颗） | 既自转又公转，**分流载荷** |
| 内齿圈 | 最外圈，多数机型与箱体固定 | **固定件** |
| 行星架 | 托着行星轮轴，与输出法兰/轴相连 | **输出** |

行星轮颗数 **不改变减速比**，只改变均载、刚度和装配难度。颗数越多，单齿受力越匀，配齿和装配越苛刻。

## 2. 怎么转起来（NGW 减速）

内齿圈固定时：

```text
电机 → 太阳轮转
  → 行星轮在齿圈里滚动（自转 + 公转）
    → 行星架把公转带出去 → 输出减速、同向、增扭
```

单级效率通常很高（工程上常按每级约 3% 啮合损失估，单级常 >95%）。要更大减速比就 **多级串联**，轴向变长、效率略降、回差累加。

## 3. 传动比（先会算，再看样本）

内齿圈固定、太阳轮输入、行星架输出时：

```text
i = n_太阳 / n_行星架 = 1 + Z_齿圈 / Z_太阳
```

- 行星轮齿数 **不出现在 i 里**，它主要保证能装进去、能均载。  
- 几何上常有 `Z_齿圈 ≈ Z_太阳 + 2 × Z_行星`（标准变位、同心条件的简化式；变位齿轮会偏这个等式）。  
- 例：齿圈 100、太阳轮 20 → `i = 1 + 100/20 = 6`。太阳轮转 6 圈，行星架转 1 圈。  
- 单级实用减速比大约 **3–10**（再小太阳轮太弱，再大行星轮太瘦）。要 16–100 用两级或三级，样本上常见 3/4/5/7/10 再组合，方便和伺服分辨率凑整数。

输出扭矩量级：`T_出 ≈ T_电机 × i × η`，选型不能拿 `T_电机 × i` 当额定，要扣效率，并单独校峰值/急停。

## 4. 固定哪一个，完全是另一种机器

同一套太阳–行星–齿圈，**固定件 / 输入 / 输出** 一换，减速比和转向都变。买关节行星减速机时先确认厂家用的是哪一档。

| 固定 | 输入 | 输出 | 结果（NGW 简化） | 关节上 |
|---|---|---|---|---|
| 内齿圈 | 太阳轮 | 行星架 | `i = 1 + Zr/Zs`，**同向减速** | **默认减速机** |
| 内齿圈 | 行星架 | 太阳轮 | 上面的倒数，**同向增速** | 几乎不用在关节 |
| 行星架 | 太阳轮 | 内齿圈 | `i = −Zr/Zs`，**反向** | 叫星型/准行星，高速定轴用得多，关节模组少见 |

差动（三件都能转、两输入）是混动/变速箱玩法，不是伺服行星减速机的默认采购口径。

## 5. 配齿必须同时满足的四件事

自己画结构或审供应商「非标齿数」时，缺一条都会装不上或打齿：

| 条件 | 一句话 |
|---|---|
| 传动比 | 齿数对得上目标 `i` |
| 同心 | 太阳–行星中心距 = 行星–齿圈中心距（变位后仍同心） |
| 装配 | 多颗行星能同时啮入；常用 `(Z_太阳 + Z_齿圈)` 能被行星颗数整除 |
| 邻接 | 相邻行星齿顶不相撞，间隙大约 > 0.5 倍模数 |

均载：制造误差会让三颗行星受力不均。高精度机型靠精度 + 浮动太阳轮/柔性销；低端箱没有均载，扭矩样本要打折。

## 6. 在机器人里干什么

需要 **效率高、转速能力强、成本相对可控** 的轴；直线关节前级、腰、轮式、部分髋。大减速比时轴向长度上去，不一定比谐波更扁。

不替代：要极薄中空、回差极小的腕/肘，谐波往往更合适。

## 7. 选型必须冻结

- [ ] 级数与总减速比（以及是不是 NGW 内齿圈固定）
- [ ] 额定 / 峰值 / 急停输出扭矩；持续工作建议落在额定的 50–70%，峰值单独校
- [ ] 回差档（arcmin）与扭转刚度 —— 两个数，别混
- [ ] 惯量：`(J_负载 / i²)` 对电机转子惯量，高精度轴常希望 ≤ 3
- [ ] 效率、噪音、最高输入转速
- [ ] 齿制：直齿 vs 斜齿（斜齿更静，但有轴向力）
- [ ] 输出：法兰 / 轴伸 / 空心；输入：止口、轴径、轴长、键
- [ ] 润滑与安装方向（有的型号限制竖直/水平）

**回差怎么测（下单要对齐定义）：** 输出端锁死，输入端正反转到约额定扭矩的 ±2%，输入端的微小转角就是回程间隙。问清是折算到输入还是输出、在哪个扭矩下测。

粗分档（厂家分档会略有出入）：

| 回差 | 大概用途 |
|---|---|
| < 3′ | 关节、精密转台 |
| 3′–10′ | 一般自动化 |
| > 10′ | 单向输送，不适合定位关节 |

## 8. 配套关系

- **电机：** 止口、轴径、键/胀套必须按电机完整型号对，不能只按「750 W 通用法兰」。斜齿行星要校电机轴轴向力。
- **结构：** 多级行星的轴向长度先占位；输出轴承许用径向/轴向/弯矩要按连杆校，不要只看扭矩。
- **控制：** 回差比谐波大时，关节侧编码器更必要。
- **减速比顺序：** 先定输出转速再反推 `i = n_电机 / n_出`，不要为了扭矩盲目加大 `i` 把节拍做没。

## 9. 验收要点

- 减速比、回差等级与订单一致（同外形不同回差档是常见货）
- 空载噪音、漏脂、输出法兰跳动
- 样品与小批是否同一齿制（直改斜会改噪音和轴向力）
- 输入适配法兰是否原厂；私改同轴差会先打死行星轮轴承

## 10. 已知坑

- 只看减速比，不看回差档，定位精度整轴被吃掉。
- 把 `T_电机 × i` 当额定，没扣效率、没校峰值和弯矩。
- 适配法兰私改，同轴差导致轴承早死。
- 当谐波的「便宜替代」用在薄壁中空关节，厚度超标、走线没孔。
- 行星轮齿数当减速比调，公式里根本没有它。
- 负载惯量折到电机轴过大，伺服振荡却怪减速机「精度不够」。
