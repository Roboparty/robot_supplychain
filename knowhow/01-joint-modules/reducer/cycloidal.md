# 摆线减速机（含 RV）

**大类：** [关节模组](../README.md) · **小类：** [减速机](./README.md)

## 1. 是什么

用摆线轮与针齿啮合传递运动。工业机器人上的 **RV** 通常是「行星前级 + 摆线主减速」，刚度高、抗冲击、适合机座和重载臂。

人形近年还有 **轻量化摆线 / 摆线关节**，目标是接近 RV 的刚度和抗冲击，但减重减厚度，不能把工业 RV 样本直接当成人形选型。

## 2. 在机器人里干什么

髋、踝、有时膝：冲击大、弯矩大、要抗失步冲击。机座旋转、升降关节也常见。

不替代：腕部极致轻薄（谐波更常见）；也不要默认「摆线 = 一定比谐波耐用」而不看重量和厚度。

## 3. 选型必须冻结

- [ ] 结构类型：工业 RV vs 人形轻量化摆线 vs 纯针摆
- [ ] 减速比、额定 / 峰值扭矩、启动停止扭矩
- [ ] 扭转刚度、回差
- [ ] 许用弯矩、轴向力（髋关节侧向力很大）
- [ ] 重量、外径、厚度、中空
- [ ] 输入与电机连接、输出法兰
- [ ] 润滑、密封、安装方向
- [ ] 效率与温升（重载连续行走）

## 4. 配套关系

- **电机：** RV 输入转速和惯量匹配；轻量化摆线常与无框电机集成为模组。
- **结构：** 输出轴承是否已集成；若没有，连杆弯矩会打到针齿。
- **控制：** 刚度高有利于力控，但重量会吃掉整机惯量预算。

## 5. 验收要点

- 类型与重量必须和图纸占位一致（工业 RV 装进人形髋会直接超重）
- 空载盘动、冲击后空程是否变大
- 漏脂、温升
- 输出端面跳动

## 6. 已知坑

- 把工业 RV 当成人形髋的「稳妥选择」，重量和厚度让整机走不起来。
- 只比扭矩不比刚度，力控振荡或落地冲击后精度掉。
- 样本寿命按工业均匀负载算，人形启停冲击谱完全不同。
