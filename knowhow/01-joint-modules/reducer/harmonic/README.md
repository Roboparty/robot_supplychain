# 谐波减速机

**大类：** [关节模组](../../README.md) · **小类：** [减速机](../README.md)

学名应变波齿轮（strain wave gear）。靠柔轮的弹性变形传动，单级就能做到大约 **30–160** 的减速比，回差极小、同轴、可中空。商标 Harmonic Drive 已成通称。

肩、肘、腕要薄、轻、换向准，默认谐波。膝、踝落地冲击大，柔轮疲劳，优先行星 / 摆线或把谐波大幅降额。

## 选型必须冻结

- [ ] 形态：杯 / 帽 / 扁平；元件组还是带壳整机；中空孔径  
- [ ] 减速比（50 / 80 / 100 / 120 / 160 等）  
- [ ] **额定 / 启动停止（反复峰值）/ 瞬时最大** 三个扭矩，不要混  
- [ ] 许用平均输入转速、瞬时输入转速  
- [ ] 空程（lost motion）或精度档；扭转刚度  
- [ ] 输出轴承许用弯矩 / 轴向 / 径向（连杆侧向力常先打轴承）  
- [ ] 输入：波发生器与电机轴配合、同轴  
- [ ] 润滑脂牌号、注脂量、是否免维护、工作温度  
- [ ] 寿命口径：小时或输入转数，对应哪条负载谱  

## 配套

- **电机：** 最高转速落在谐波许用输入内；波发生器常与内转子轴直连。见 [无框电机](../../frameless-motor/README.md)。  
- **编码：** 电机侧看换向；关节侧看柔轮/输出真实角（回差和柔轮变形都在这边）。  
- **结构：** 刚轮座、交叉滚子安装面平面度决定空程和寿命。  

## 一句话坑

瞬时最大当额定 → 柔轮裂纹；弯矩超轴承 → 关节晃、编码跳；输入转速过高 → 脂干、寿命断崖；同轴差 → 空载周期性噪音当电机齿槽去调。
