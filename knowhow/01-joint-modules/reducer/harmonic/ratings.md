# 谐波额定、精度与寿命

**大类：** [关节模组](../../README.md) · **小类：** [减速机](../README.md) · **细分：** [谐波](./README.md)

样本上至少三套扭矩、两套转速、一条寿命。只抄「额定 Nm」会把柔轮开裂写成质量问题。

## 三个扭矩不要混

| 名称（厂家叫法会略有出入） | 何时用 | 乱用不行 |
|---|---|---|
| **额定输出扭矩** | 额定转速、额定寿命下可连续/等效的扭矩 | 当行走循环的平均值来比 |
| **启动停止 / 反复峰值** | 加减速、频繁启停 | 当额定用，寿命按立方掉 |
| **瞬时最大 / 紧急** | 碰撞、急停一次 | 当额定或反复峰值 |

还有一个 **棘齿扭矩（ratcheting）**：运动中扭矩大到柔轮/刚轮对不进齿，跳齿。有的样本到额定的数倍。棘齿后同轴被破坏，继续转会很快把柔轮转裂。过载保护要按瞬时和棘齿来，不能只靠驱动限流「感觉」。

等效负载要用负载谱，不能用峰值。厂家常用近似（以样本 N–T 曲线为准）：

```text
L ≈ (T_额定 / T_等效)^3 × L_额定
```

`L` 常以 **输入转数** 或小时计。额定寿命口头有 10⁴ 小时或 10⁷～2×10⁷ 转一档，**必须对上该型号表**。扭矩多用 10%，寿命不是多用 10%。

柔轮每转经历 **两次** 椭圆变形循环，疲劳在柔轮齿根/筒壁；波发生器柔性轴承也是寿命件。高温、脂干、同轴差会一起加速。

## 转速

- **许用平均输入转速：** 连续走、热和脂能接受  
- **许用瞬时输入转速：** 短时  

输入转速过高：柔性轴承和啮合发热，脂失效，寿命断崖。内转子电机空载转速很容易超谐波输入限——G0 就要对电机 Kv 和谐波限速。

## 空程、回差、刚度

谐波啮合区预紧，**真齿隙（backlash）接近零**。样本更多给：

| 量 | 是什么 |
|---|---|
| **空程 lost motion** | 正反加小扭矩（常约 ±额定的百分之几）测到的角差，含弹性迟滞 |
| **传动误差** | 输入匀速时输出角相对理论的波动 |
| **扭转刚度** | 扭矩–转角曲线的斜率，常分段（小扭矩软、大扭矩硬） |

控制振荡、末端晃，经常是刚度不够或弯矩打轴承，不是「回差 1 角分不够小」。空程、精度档、刚度三条都要冻。

## 弯矩与力

输出交叉滚子（或你自己的轴承）有：径向、轴向、**许用弯矩**。人形小臂质量 × 力臂很容易超。超了：交叉滚子预紧消失 → 空程变大 → 编码跳变。校核用最坏姿态，不要用「竖直挂着」的扭矩。

## 效率与发热

单级比大，效率通常低于同功率行星（常见口头 70–85% 量级，高速更差）。损耗进脂和柔轮。封闭关节没有对流，连续转矩看热，和电机壳体是同一条路。

## 冻结时对照负载谱

- [ ] 等效扭矩 ≤ 额定，反复启停 ≤ 反复峰值，碰撞 ≤ 瞬时且远离棘齿  
- [ ] 平均 / 瞬时输入转速  
- [ ] 空程档、刚度、许用弯矩  
- [ ] 寿命按哪条曲线、多少转/小时
