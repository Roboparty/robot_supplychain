# 摆线 / RV 结构与形态

**大类：** [关节模组](../../README.md) · **小类：** [减速机](../README.md) · **细分：** [摆线](./README.md)

先分清：单级针摆是 **K-H-V**；工业 **RV** 是把它用差动封闭起来，再加一级渐开线行星。曲柄轴两端支撑，这才是 RV 比老式悬臂针摆硬的原因。

## 纯针摆（单级 K-H-V）

| 构件 | 干什么 |
|---|---|
| **偏心轴**（转臂 H） | **输入**，偏心撑着摆线轮公转 |
| **摆线轮** | 短幅外摆线齿廓，齿数比针齿少（常少 1） |
| **针轮**（针齿销 + 针齿壳） | 内圈针齿，常 **固定在壳体** |
| **W 输出机构** | 销孔或输出盘，把摆线轮的自转送出去 |

针齿固定时，单级比：

```text
i = Z_针 / (Z_针 − Z_摆)     （常 Z_针 = Z_摆 + 1 → i ≈ Z_摆）
```

同时啮合齿数可以很多（厂家常宣传近半数针齿），所以抗冲击、刚度好。老式单偏心 **悬臂**：径向力要壳体硬扛，精度和寿命都不如 RV。两片摆线盘相位差 180°，用来抵消偏心不平衡。

库氏记号 K-H-V 见 [行星结构类型](../planetary/types.md)，不要和 NGW 公式混用。

## RV：行星前级 + 摆线主减速

工业六轴上的 RV 默认是这套，不是「加厚的针摆」。

| 构件 | 干什么 |
|---|---|
| **太阳轮 / 齿轮轴** | **输入**，接电机 |
| **行星轮**（常 2 或 3 个） | 与太阳轮外啮合，和 **曲柄轴固连** |
| **曲柄轴**（偏心轴） | 两端分别撑在输出盘和针齿壳侧轴承上（**双支撑**） |
| **两片摆线盘** | 相位差 180°，套在曲柄偏心上，与针齿啮合 |
| **针齿壳 + 针齿** | 常 **固定在机座/关节座** |
| **输出盘 / 行星架** | 曲柄轴的公转送到法兰，**输出** |

电机转太阳轮 → 行星轮自转带着曲柄转 → 摆线盘既公转又相对针齿错齿 → 输出盘把曲柄的公转送出去。第一级行星是差动件，第二级针摆是封闭件，**总比不是两级比简单相乘**。

针齿壳固定、太阳轮入、输出盘出，且针齿数比摆线齿数多 1 时，常用验算（下单仍以样本为准）：

```text
i = 1 + (Z_行星 / Z_太阳) × Z_针
```

例：太阳 12、行星 36、针齿 40 → `i = 1 + 3 × 40 = 121`。转向、谁固定写进图纸；输出盘固定、针齿壳输出是另一套公式。

曲柄 **2 根**（相隔 180°）或 **3 根**（120°）：三根均载更好，工业 RV 更常见。两片盘抵径向力，曲柄两端支撑抗倾覆——刚度来自这里，不是「牌子叫 RV」。

## 实心 / 中空、元件组 / 整机

| 交付 | 你拿到什么 |
|---|---|
| **元件组** | 针齿壳、输出盘、摆线盘、曲柄，壳体和密封自己做 |
| **带壳整机** | 有安装法兰、已注脂，工业机器人常用 |
| **中空规格** | 太阳轮/曲柄让出中心孔走线、通轴；孔径和线束一起冻 |
| **实心轴** | 扭矩密度往往更好，走线要绕开 |

口头系列只作认图：实心、中空、高刚性紧凑档。同外形不同档额定差一截，BOM 不能只写「某号 RV」。

## 人形轻量化摆线

目标：髋膝抗冲击接近 RV，但减重减轴向。常见手段：铝壳、少针齿、更薄摆线盘、单级针摆、或缩小的两级。主轴承和曲柄轴承截面跟着缩小，**许用弯矩不能按工业 RV 同扭矩档抄**。

和 [谐波](../harmonic/structure.md) 怎么配：

```text
换向准、薄、中空、上肢
  → 谐波

抗落地冲击、髋踝弯矩、要扭转刚度
  → RV / 轻量化摆线（先冻重量厚度）

要转速、效率、成本，冲击不大
  → 行星
```

RV 不是「更耐用的谐波」。寿命件是针齿、曲柄轴承、主轴承；谐波寿命件是柔轮。重量预算不够时，降额谐波或准直驱行星，不要默认上工业 RV。
