# 摆线减速机（含 RV）

**大类：** [关节模组](../../README.md) · **小类：** [减速机](../README.md)

针齿和摆线齿廓啮合，多齿同时接触，刚度高、抗冲击。工业机器人基座和重载臂上的默认件叫 **RV**（Rotary Vector 已成通称）：**渐开线行星前级 + 摆线主减速**，曲柄轴两端支撑。单级针摆、人形轻量化摆线是同一族，不是同一张样本。

| 页 | 讲什么 |
|---|---|
| [结构与形态](./structure.md) | 纯针摆 K-H-V vs RV 两级封闭；双盘、曲柄轴、中空 |
| [额定与寿命](./ratings.md) | 三档扭矩、刚度、弯矩、回差；寿命看轴承不是柔轮 |
| [装配与润滑](./assembly.md) | 针齿成套、主轴承预紧、脂量、安装方向 |

髋、踝、有时膝：冲击和弯矩大，谐波柔轮吃不住时看摆线。腕、肘要薄要中空，不要拿工业 RV 硬塞。

## 三种不要混下单

| | **工业 RV** | **纯针摆**（单级） | **人形轻量化摆线** |
|---|---|---|---|
| 结构 | 行星前级 + 双摆线盘 + 曲柄双支撑 | 偏心轴 + 针齿，偏心常悬臂 | 针摆或缩小 RV，铝壳、少针、减壁 |
| 刚度 / 抗冲 | 工业六轴默认 | 低于 RV，径向力难抵消 | 介于谐波和工业 RV，以该型号表为准 |
| 重量 / 厚 | 小规格也常数公斤、轴向厚 | 可更扁，看怎么做壳 | 为髋膝减重，**不能拿工业 RV 重量去比** |
| 交期 / 成本 | 成熟、重载档贵 | 看厂家 | 人形定制多，规格绑定模组 |

BOM 只写「摆线」会把工业 RV 装进人形髋。类型、重量、厚度必须和占位一起冻。

## 选型必须冻结

- [ ] 类型：工业 RV / 纯针摆 / 轻量化摆线；元件组还是带壳整机  
- [ ] 实心轴还是中空；中空孔径与走线  
- [ ] 减速比（常见 30–200 档，以样本为准）  
- [ ] **额定 / 启动停止 / 瞬时最大** 三个扭矩，不要混  
- [ ] 扭转刚度、回差或空程档  
- [ ] 许用弯矩、轴向 / 径向（髋侧向力常先打主轴承）  
- [ ] 重量、外径、厚度  
- [ ] 输入：太阳轮/齿轮轴与电机轴配合、许用输入转速  
- [ ] 润滑脂、注脂量、安装方向（立式/卧式脂分布不同）  
- [ ] 寿命口径对应哪条负载谱，不是工业均匀负载直接套人形  

## 配套

- **电机：** 输入转速和转子惯量要落在 RV 许用内；轻量化摆线常与无框集成为模组。见 [无框电机](../../frameless-motor/README.md)。  
- **编码：** 电机侧换向；关节侧看输出盘真实角（回差和主轴承游隙都在这边）。  
- **结构：** 针齿壳、输出盘安装面平面度；主轴承是否已集成，没有则连杆弯矩打到针齿。  

## 一句话坑

工业 RV 当人形髋「稳妥件」→ 重量厚度让整机走不起来；只比扭矩不比刚度和弯矩 → 落地后空程变大；样本寿命按工业均匀负载 → 人形启停谱完全不同。
