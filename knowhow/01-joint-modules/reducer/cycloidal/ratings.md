# 摆线 / RV 额定、刚度与寿命

**大类：** [关节模组](../../README.md) · **小类：** [减速机](../README.md) · **细分：** [摆线](./README.md)

RV 样本同样是三套扭矩、刚度、弯矩、一条轴承寿命。谐波怕柔轮疲劳；RV 怕主轴承和针齿磨损。只抄「额定 Nm」会把工业件装进人形髋。

## 三个扭矩不要混

| 名称（厂家叫法会略有出入） | 何时用 | 乱用不行 |
|---|---|---|
| **额定输出扭矩** | 额定转速、额定寿命下的等效/连续扭矩 | 当行走平均值来比还行；当峰值不行 |
| **启动停止 / 加速扭矩** | 加减速、频繁启停 | 当额定用，轴承寿命按立方掉 |
| **瞬时最大 / 冲击** | 碰撞、急停、落地一次 | 当反复峰值。工业 RV 瞬时常到额定数倍，**反复冲击仍磨针齿** |

等效负载用负载谱。轴承寿命厂家常用近似（以样本为准）：

```text
L ≈ (T_额定 / T_等效)^3 × L_额定
```

`L` 常以小时或输出转数计。工业口头有 6000 h 一档，对应的是工业均匀循环，**不是人形蹲起谱**。扭矩多用 10%，寿命不是多用 10%。

寿命件优先：**主轴承**（弯矩）、**曲柄轴轴承**（偏心载荷）、针齿/摆线啮合面。没有柔轮那种每转两次的弹性疲劳，但脂干、过弯矩、针齿点蚀一样会把空程做大。

## 转速与效率

- **许用平均输入转速、瞬时输入转速** 都要冻。输入过高：曲柄轴承和啮合发热，脂失效。  
- 效率通常低于同功率 NGW 行星、高于同比高速谐波一档（口头常 70–85% 量级，高速、大比更差）。损耗进脂和针齿。封闭髋关节连续转矩看热。

## 回差、空程、刚度

RV / 针摆靠多齿啮合和主轴承预紧把齿隙做小。样本常给：

| 量 | 是什么 |
|---|---|
| **回差 backlash** | 输出端齿隙角，工业精密档常到角分级 |
| **空程 lost motion** | 正反加小扭矩测到的角差，含弹性 |
| **扭转刚度** | 扭矩–转角斜率；同扭矩档通常 **明显高于谐波** |

髋膝力控振荡、落地后「关节松了」，经常是刚度不够或主轴承弯矩超了，不是减速比选小了。刚度、回差、许用弯矩三条分开冻。

## 弯矩与力

输出主轴承（角接触、圆锥或交叉滚子，看系列）有径向、轴向、**许用弯矩**。人形髋：躯干质量 × 力臂，最坏姿态校核。超了：预紧消失 → 空程变大 → 编码跳，看起来像减速机「精度不行」。

工业 RV 弯矩能力是卖点；轻量化摆线把轴承做薄之后，**弯矩才是瓶颈**，不要按同额定扭矩的工业表抄。

## 重量是规格

工业小规格 RV 也常到数公斤、轴向厚。人形单髋整轴（电机+减速+结构）预算可能就这个量级。冻结项里重量、厚度与扭矩同级，验收按图纸占位称重，不接受「扭矩够了先装上」。

## 冻结时对照负载谱

- [ ] 等效扭矩 ≤ 额定，反复启停 ≤ 加速档，碰撞 ≤ 瞬时  
- [ ] 平均 / 瞬时输入转速  
- [ ] 回差档、扭转刚度、许用弯矩  
- [ ] 重量、厚度、中空  
- [ ] 寿命按哪条曲线；人形谱不要套工业 6000 h 口头值
