# 谐波减速机

**大类：** [关节模组](../README.md) · **小类：** [减速机](./README.md)

## 1. 是什么

谐波传动靠 **波发生器 + 柔轮 + 刚轮** 的齿差啮合减速。柔轮被椭圆波发生器撑圆，与刚轮啮合；柔轮转一圈相对刚轮只走过齿差，从而得到大减速比。

常见形态：杯型柔轮、帽子型、一体机座带交叉滚子轴承。人形关节多用扁型、可中空走线的规格。

## 2. 在机器人里干什么

肩、肘、腕等要求 **薄、轻、回差小** 的轴。膝、髋也能用，但冲击和弯矩要按样本校核，不能只看臂上用过同型号。

不替代：需要频繁抗冲击的重载轴（更常看摆线 / RV 或降额很大的谐波）。

## 3. 选型必须冻结

- [ ] 减速比（如 50 / 80 / 100 / 120）
- [ ] 额定扭矩、启动停止扭矩、瞬时最大扭矩（三个数不要混）
- [ ] 许用平均输入转速、瞬时输入转速
- [ ] 输出回差或谐波传动精度等级
- [ ] 输出轴承许用弯矩 / 轴向力（连杆侧向力常把轴承打坏）
- [ ] 中空孔径、厚度、输入端与电机轴配合
- [ ] 润滑脂牌号与是否免维护
- [ ] 安装：波发生器与电机轴同轴度要求

## 4. 配套关系

- **电机：** 转子惯量、最高转速必须落在谐波许用输入转速内；波发生器常与电机轴直连或一体。
- **编码：** 双编码器时，电机侧看换向，关节侧看柔轮/输出端真实角。
- **结构：** 刚轮座与交叉滚子的安装面平面度，直接影响回差和寿命。

## 5. 验收要点

- 铭牌减速比、安装方向与 PO 一致
- 空载盘动：卡滞、异响
- 台架：空程、传动误差、温升（按约定转速/扭矩）
- 禁止用锤子敲波发生器装配

## 6. 已知坑

- 把瞬时最大扭矩当额定用，柔轮很快疲劳裂纹。
- 侧向力和弯矩超轴承许用，表现为关节晃、编码器跳变。
- 输入转速过高，发热把润滑打掉，寿命断崖。
- 装配同轴差，空载就有周期性噪音，当「电机齿槽」去调。
