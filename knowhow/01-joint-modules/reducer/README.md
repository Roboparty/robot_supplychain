# 减速机

**大类：** [关节模组](../README.md)

把电机的高速、小扭矩变成关节需要的低速、大扭矩，并提供刚度与定位精度。减速比、回差、刚度、重量、中空走线，决定这一轴能不能用于髋、膝还是腕。

## 细分

| 细分 | 典型特征 | 人形上常见位置 | 入口 |
|---|---|---|---|
| 谐波 | 齿比大、体积小、回差小、柔轮怕冲击 | 肩、肘、腕、部分膝 | [harmonic.md](./harmonic.md) |
| 行星 | 效率高、可多级；结构见 NGW/NW，齿轮见模数/齿系 | 需要转速/成本折中的轴 | [planetary/](./planetary/README.md) |
| 摆线（含 RV） | 刚度高、抗冲击、往往更重 | 髋、踝等重载；轻量化摆线也在膝/髋 | [cycloidal.md](./cycloidal.md) |

准直驱 / 无减速是另一条路：几乎不经过减速机，靠电机本体扭矩。外转子更常见，见 [无框力矩电机](../frameless-motor/README.md)。

## 三种怎么比（选型，不是报价）

| 维度 | 谐波 | 行星 | 摆线 / RV |
|---|---|---|---|
| 单级减速比 | 常见 30–160 | 单级约 3–10，要大比就多级 | 常见 30–200 |
| 回差 / 空程 | 可做到很小 | 看齿隙与级数，通常大于谐波 | 可很小，刚度好 |
| 抗冲击 | 弱，柔轮易疲劳 | 中 | 强 |
| 效率 | 中，高速发热要盯 | 高 | 中 |
| 重量 / 外径 | 扁、轻，利于臂 | 看级数 | 工业 RV 偏重；人形摆线在减重 |
| 中空走线 | 常见 | 看结构 | 看结构 |
| 成本与交期 | 高精度档贵、交期紧 | 相对好买 | 重载档贵 |

## 减速机共通冻结项

- [ ] 减速比、额定 / 峰值扭矩（输出端）
- [ ] 输入转速上限、许用弯矩
- [ ] 回差 / 迟滞、扭转刚度
- [ ] 寿命口径（小时或启停次数）与润滑方式
- [ ] 输入/输出法兰、中空孔径
- [ ] 与电机轴的连接（胀套、键、一体波发生器）

## 共通坑

- 按「样本峰值扭矩」选，实际是短时冲击值，行走循环里过热或柔轮裂。
- 输出法兰与连杆惯性不匹配，刚度看起来够、控制振荡。
- 只锁减速机型号，不锁与电机的同轴和波发生器匹配。
