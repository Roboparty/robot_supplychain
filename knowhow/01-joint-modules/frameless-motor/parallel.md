# 力矩电机并联

**大类：** [关节模组](../README.md) · **小类：** [无框力矩电机](./README.md)

单台转矩不够，可以把多台装在 **同一根轴** 上耦合。来源归纳：[挽风笔记](https://zhuanlan.zhihu.com/p/697917097) §5。

## 主机 / 从机

- 轴上第一台是 **主机**，定正反转。  
- 其余是 **从机**。电缆可一前一后，或面朝两面。  
- 电气上并联到同一驱动或按厂家接线；线序反了等于对着干。

## 相角度校准

电气相位不一致：功率因数和 Kt 掉、噪音、过热、过载报警。

每转一圈定子三相感应电动势，从机 EMF 相位必须跟主机对齐。

```text
机械安装角 = 电气相位角 / 极对数
```

两台电气相位偏差应 **小于 ±5°**（该文静态功能口径）。轴慢转，双通道示波器看两台反电势，算相位差，再转转子或定子把机械角拧掉。

## 伺服调试

先做磁极位置检测（PolID），再按单电机方式整电流环、速度环、位置环。并联不是「电流加一倍就结束」。

## 冻结

- [ ] 是否并联、几台、主从布置和出线方向  
- [ ] 极对数、相位校准记录（电角 / 机械角）  
- [ ] 驱动是否支持并联 / 主从  

坑：只并联功率线不校相位；把两台电气当成机械 180° 对称就完事（要用极对数换算）。
