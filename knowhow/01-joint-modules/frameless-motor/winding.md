# 定子绕线

**大类：** [关节模组](../README.md) · **小类：** [无框力矩电机](./README.md)

定子叠片开槽之后，铜线怎么进槽，决定 **电阻、端部高度、槽满率、焊点和一致性**。槽极决定「能不能三相对称」，绕线决定「同样槽极能做出多低的铜耗、多短的轴向」。槽极见 [slot-pole.md](./slot-pole.md)，冲片见 [core.md](./core.md)。

## 绕组拓扑（电气）

| 方式 | 是什么 | 无框关节 |
|---|---|---|
| **集中绕组** | 一齿一线圈，跨距 1 槽 | **默认**。端部短，可分瓣绕 |
| **分布绕组** | 线圈跨若干槽，短距/整距 | 高速整数槽伺服；轴向和端部通常更厚 |
| 单层 | 一槽只落一层线圈边 | 绝缘简单，槽满率一般 |
| 双层 | 一槽两层（常属不同相或同相） | 更灵活；相间绝缘要冻 |

接线：

| | 星接 Y | 角接 Δ |
|---|---|---|
| 线电压 / 相电压 | 线 = √3 相 | 相等 |
| 同样匝数 | 反电势更高、电流更小 | 反电势低、电流大 |
| 关节里 | **更常见**（匹配高压母线、小线径） | 低压大电流、或特意降 Ke |

换电压方案，优先动 **匝数 / 并联支路 / 星角**，不要先改冲片。

```text
相电阻 ∝ 匝数² / 并联支路数
Ke、Kt ∝ 匝数 / 并联支路数     （同一铁心、同一槽满）
```

## 多股并绕 vs 多联绕

口头容易混，下单要拆开写。

**多股并绕（并绕）：** 一匝不是一根粗线，而是 **N 根细线并联当一匝**。

- 细线好绕、槽满率往往更高，绝缘漆包占比也更高。  
- 电频率上去以后，趋肤 / 邻近效应比一根粗圆线轻（再往上才是利兹线，关节少见）。  
- 冻：股数、单股线径、并绕后等效截面积。  
- 坑：股间虚焊、某股断了电阻飘；并绕根数变了当「同一规格」。

**多联绕（联绕）：** 绕线机 **一次同时绕多个线圈**（双联、三联、四联…），或一根线连续绕过若干齿再剪断。

- 焊点少、节拍快，适合集中绕组批量。  
- 联数要和槽极、三相出线对上：联得不对，可能变成不该串联的齿被串在一起，三相对称和并联支路数都变。  
- **单联：** 一次绕一只线圈，灵活、慢、焊点多。  
- 坑：把「三联绕」理解成「三股并绕」，电阻、Ke 对不上还怪厂家。

并联支路数 `a` 是电气量（一相里几路并联）；联绕是工艺量。两者相关，但不是同一个字段。

## 绕线工艺

| 工艺 | 怎么绕 | 槽满率 | 配什么铁心 |
|---|---|---|---|
| **飞叉绕** | 线架绕齿转 | 高 | **分瓣齿** 最熟 |
| **针绕** | 针从槽口伸进整圆定子绕 | 中（槽口要留针） | **整圆定子** |
| 手工 / 半自动 | 样机、小批 | 看人 | 都行，一致性差 |
| 嵌线 | 成型线圈再嵌入 | 分布绕组用 | 整圆整数槽 |

槽口窄 → 针进不去 → 槽满率上不去，连续转矩先掉。要高槽满率，通常 **分瓣齿 + 飞叉**，不是在整圆上把针绕「再挤一点」。

浸漆 / **VPI**（真空压力浸渍）：把绕组结成固体、导热和耐振。干绕组或只滴漆的样机，上机振动和温升会和样品两套数。

## 槽满率与端部

- **槽满率：** 铜（含漆）占槽有效面积。整圆针绕常见大约 **40–55%**；分瓣飞叉常见 **60–75%** 量级（厂家口径，下单写进图纸）。  
- 槽满率高：电阻低、连续转矩好；太满则嵌线伤漆、散热差、合格率掉。  
- **端部高度** 直接吃轴向。无框短 `LS` 时，端部往往比叠厚还高；集中绕组就是为了砍端部。  
- 出线：外圆径向出还是端面出，和壳体、轴承盖一起冻。见 [assembly.md](./assembly.md)。

## 冻结清单

- [ ] 集中 / 分布；单层 / 双层；星 / 角  
- [ ] 每相串联匝数、并联支路数 `a`  
- [ ] 并绕股数与单股线径（不要只写「线径 0.5」）  
- [ ] 联绕：单联 / 双联 / 多联，和出线、焊点方案  
- [ ] 槽满率目标、端部最大轴向  
- [ ] 绝缘等级（常见 F/H）、浸漆还是 VPI  
- [ ] 相电阻、反电势公差（冷态）  

## 验收

- 三相电阻不平衡（常见要 &lt; 3–5%，按合同）  
- 绝缘耐压、匝间（脉冲）  
- 端部不超轴向包络；出线位置与图纸一致  
- 拆一齿抽检：股数、匝数、有无交叉伤漆  

## 已知坑

- 「多联绕」和「多股并绕」当同一个 PO 字段。  
- 整圆针绕的槽满率，按分瓣飞叉的连续转矩去对壳体温升。  
- 只改线径不改匝数，Ke 变了驱动限流全套作废。  
- 浸漆工艺样品有、小批没有，振动后匝间先挂。  
- 星点焊在端部最鼓的地方，壳体一压就破绝缘。
