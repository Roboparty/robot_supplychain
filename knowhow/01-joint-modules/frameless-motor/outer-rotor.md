# 外转子无框力矩电机

**大类：** [关节模组](../README.md) · **小类：** [无框力矩电机](./README.md)

## 1. 是什么

定子在中心不动，转子（磁钢在内壁）包在定子外面转。气隙在更大半径上，同样外径下力臂更长，扭矩密度通常高于内转子。外形相对 **扁平**（径大、轴短）。转子惯量更大。

## 2. 在机器人里干什么

髋、膝、踝、外骨骼、需要爆发力的腿：直驱或 **低减速比准直驱**（常见行星 6–10 档），少用高减速谐波。力透明度和可回驱更好，电流环估力矩更靠谱；代价是散热、同轴、径向空间。

装配吸力、并联相位、液冷对连续转矩的影响见 [assembly.md](./assembly.md)、[parallel.md](./parallel.md)、[thermal.md](./thermal.md)。外转子气隙在定子外圆与转子内圆之间，工装防吸死同样适用，径向力往往更猛。

## 3. 选型必须冻结

- [ ] 确认是外转子：转子外圆往往就是「看起来像壳」的那圈，但无框仍然没有轴承
- [ ] 额定 / 峰值扭矩、连续转矩（连续值强烈依赖壳体导热）
- [ ] 最高转速（通常低于同尺寸内转子）
- [ ] 定子如何导热：灌封、过盈、液冷套；没有热路径就没有连续转矩
- [ ] 气隙在定子外圆与转子内圆之间；装配工装必须防吸死、防擦磁钢
- [ ] 转子磁钢：外转子离心力在磁钢上，高速/高加速要问粘接或护套，必要时 IPM
- [ ] 径向空间、与连杆/谐波是否干涉
- [ ] 控制：大惯量，电流环防超调；直驱时负载惯量没有 `1/i²` 缩小

## 4. 配套关系

- **减速机：** 可以直驱；要减速优先低比行星（准直驱），不要默认再套 100 档谐波把力臂优势做没。
- **散热：** 定子被转子包住，热只能从定子内孔或端面导到结构。导热胶、灌封、液冷是规格的一部分。
- **结构：** 安装面要刚。外转子对同轴和圆度更敏感，偏差直接变转矩波动和单边磁拉力。
- **编码：** 大中空方便走线，但编码安装半径和屏蔽要单独冻。
- **抱闸：** 扁平关节里轴向空间紧，闸和转子外圆容易打架。

## 5. 验收要点

- 转子内圆、定子外圆、轴向厚度
- 磁钢粘接/锈蚀；盘动有无刮擦
- 反电势、齿槽；装机后连续温升（必须带真实壳体）
- 高加速后磁钢是否位移（样品台架）

## 6. 已知坑

- 样本连续转矩按理想水冷壳体测，装进封闭髋关节立刻降额。
- 当内转子用法配高减速谐波，又重又扁，谐波输入转速还可能不够。
- 无导向套装配，磁钢被定子吸过去磕掉一块。
- 只比峰值扭矩，惯量大导致电流环振荡，怪驱动器。
- 外转子当「有壳电机」拎着外圆当轴承用。

## 什么时候选它

首要目标是同样体积更大扭矩、直驱或低减速、腿部周期性负载，并且结构侧愿意做散热和同轴。髋膝踝、外骨骼优先。
