# 无框力矩电机

**大类：** [关节模组](../README.md)

只提供 **定子 + 转子**（有时含霍尔 / 温敏），没有壳体、轴承、轴、编码器。关节厂把它嵌进自己的轴承和减速结构里，换中空、薄、高扭矩密度。

第一刀分类不是品牌，是 **转子在定子里还是包在定子外**：

| 细分 | 结构 | 默认用法 | 入口 |
|---|---|---|---|
| 内转子 | 转子在内，定子包在外面 | 配谐波 / 行星，高速小惯量 | [inner-rotor.md](./inner-rotor.md) |
| 外转子 | 定子在内，转子当外壳转 | 直驱或低减速比准直驱，低速大扭 | [outer-rotor.md](./outer-rotor.md) |

还有带壳的盘式 / 轴向磁通电机，选型逻辑部分相近，但安装接口不同，不在本小类。

## 和无刷整机（带壳 BLDC）差在哪

| | 无框力矩电机 | 带壳 BLDC |
|---|---|---|
| 交付物 | 定子、转子两件 | 壳 + 轴 + 轴承 + 电机 |
| 气隙 / 轴承 | **你自己的结构决定** | 厂里已经定好 |
| 散热 | 靠关节壳体导热 | 靠电机外壳 |
| 典型关节 | 定制模组、中空走线 | 外挂电机 + 减速箱 |

无框不是「更好的 BLDC」，是把机械、热、同轴全部交给结构件。气隙不均，驱动再好也扫膛。

## 为什么扭矩差这么多

电磁转矩大致跟 **气隙处的力臂** 走：同样外径和电磁负荷，气隙直径越大，扭矩越大。外转子把磁钢放在更大半径上，所以同样体积更「有劲」、转速和加速往往更慢。内转子力臂短，扭矩要靠减速比补。

粗算：`T ≈ Kt · I`（恒转矩区）。转速上去反电势顶到母线电压，进入弱磁，力矩掉——样本峰值扭矩不能拿到高速区用。

## 两种怎么选（关节）

```text
要高速、配谐波/行星、散热走外壳、腕/肘/小臂
  → 内转子

要低速大扭、直驱或 6–10 档准直驱、髋膝踝、扁平关节
  → 外转子（必须先有散热和同轴方案）
```

没有绝对优劣。先冻：直驱还是几档减速、外径/厚度预算、连续行走温升、中空走线。

## 小类共通冻结项

- [ ] **内转子还是外转子**（样品和外购不能混）
- [ ] 额定 / 峰值扭矩、额定转速、电压、Kv / Kt
- [ ] 外径、内径（中空）、轴向叠厚、重量
- [ ] 极槽配合、齿槽转矩、转矩波动
- [ ] 绕组、线规、绝缘等级、温敏
- [ ] 磁钢牌号与最高工作温度（UH/EH 等）
- [ ] 气隙标称值、定子过盈/胶接、转子过盈/螺钉
- [ ] 霍尔有无、线长与出线方向

## 共通坑

- 内/外转子按「看起来都是无框」互替，法兰和气隙全对不上。
- 只看峰值扭矩，连续转矩和壳体热阻不够，走十分钟降功率。
- 气隙不均当「驱动调不好」。
- 直驱把负载惯量直接砸在电机上，没有 `1/i²` 缩小，电流环振荡。
