# 无框力矩电机

**大类：** [关节模组](../README.md)

只提供 **定子 + 转子**（可选霍尔、温敏），没有轴、轴承、外壳。属于永磁同步电机的「出力部分」。机器人要轻、小、扭矩大、动态快；无框和空心杯都常见，本小类只记无框。

衡量指标是 **输出扭矩**，不是普通伺服那套「额定功率」。驱动器用 UVW 造旋转磁场，转子永磁跟随；反馈可以是霍尔，也可以外加编码器，做成伺服。

第一刀分类是 **转子在里还是在外**（该文示意图默认内转子，如科尔摩根 TBM2G：转子钢环在内、定子绕组在外）：

| 细分 | 结构 | 默认用法 | 入口 |
|---|---|---|---|
| [内转子](./inner-rotor.md) | 转子在内，定子贴壳 | 配谐波 / 行星 | 该文主要口径 |
| [外转子](./outer-rotor.md) | 定子在内，转子包在外转 | 直驱 / 准直驱 | 扭矩密度另一条路 |

## 必须看的样本曲线

不要只抄额定转矩。核心是 **转矩–转速曲线**：

- `M0*`：相位电流失衡时的热静态转矩（静止、短时点动、转速过低）
- `M0`：约 1 rpm、三相负载和损耗均匀时的转矩
- 拐点：峰值转矩开始掉、额定转矩开始掉
- 更高转速段：弱磁（该文拐点 7 / 2 / 4 一类）

有电气制动时还要 **转速–短路制动转矩** 曲线。峰值转矩不能拿到弱磁区当额定用。

## 尺寸从哪来

给定转速和计算功率时，电枢直径与有效长度被 **线负荷 A**、**气隙磁密基波 Bδ** 卡住（陈世坤《电机设计》）。外壳径、轴向已经限死，再把 A 拉高：定子去磁、用铜、铜耗、温升一起恶化。

该文经验相关（定制仍看电磁方案）：

| 想要 | 主要杠杆 |
|---|---|
| 更大扭矩 | 定子叠厚 `LS` 或外径 `ΦD` 加大 |
| 更高转速 | 电压或绕组方案 |
| 更大中空 | 压缩磁路；磁钢改贴导磁轴可减一层衬套厚度 |
| 更短轴向 | 出力勉强能留，温升变差，要仿真 |

该文调研的定制量级：电压 DC 12–300 V 或 AC 220 V，功率 ≤10 kW，扭矩 ≤60 N·m；霍尔、温敏可选。当作「能问到什么」，不是承诺上限。

## 拓扑（该文默认方案）

- **分数槽集中绕组 + 多极多槽**：端部短，轴向短，转矩波动小  
- **表贴式转子（SPM）**：气隙磁密高、磁钢外圆好做正弦，谐波和转矩波动好压  
- 高饱和导磁材料抬齿/轭磁密；高矫顽力磁钢保温升后的磁负荷  

外转子、IPM 不在该文展开，见 [outer-rotor.md](./outer-rotor.md)。

## 选型五问

1. 最大转矩，以及负载循环的 **有效转矩**  
2. 期望转速和角加速度  
3. 安装空间（外径、中空、轴向）  
4. 驱动配置（母线、是否并联，见 [parallel.md](./parallel.md)）  
5. 冷却方式（见 [thermal.md](./thermal.md)）  

然后再冻内/外转子。有效转矩不是峰值，连续走看热。

## 冻结清单

- [ ] 内转子还是外转子  
- [ ] 电压、外径、中空、轴向长度、质量、转动惯量  
- [ ] 额定 / 空载转速，额定 / 峰值转矩，**T–n 曲线**（含弱磁段）  
- [ ] 需要时：短路制动曲线  
- [ ] 极槽、表贴/内置、霍尔有无、温敏回路（PTC / KTY）  
- [ ] 气隙标称（该文约 0.5 mm）、配合（松配胶接或过盈）、同轴  
- [ ] 冷却：自然 / 壳体 / 液冷  

## 共通坑

- 用额定功率当关节电机指标。  
- 只看峰值转矩，不看 `M0`、拐点和壳体热阻。  
- 气隙不均当驱动问题。  
- 协作关节 FOC 已经上编码器，还把霍尔当主反馈。  
- 无工装塞转子，轴向吸力突然放大把磁钢磕了。
