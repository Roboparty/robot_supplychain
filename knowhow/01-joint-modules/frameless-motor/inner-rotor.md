# 内转子无框力矩电机

**大类：** [关节模组](../README.md) · **小类：** [无框力矩电机](./README.md)

## 1. 是什么

转子（磁钢环）在里面转，定子绕组包在外面、贴关节壳体。工业伺服最熟的拓扑。外形相对 **细长**，中心可以中空，但中空孔径一般小于同外径的外转子。

## 2. 在机器人里干什么

协作臂和小臂关节的默认肌肉：**内转子 + 谐波**（或精密行星）。转速高、惯量小，动态跟得上；输出扭矩靠减速比。腕、肘、肩的高速轴常见。准直驱髋膝也有人用，但同样外径往往扭不过外转子。

不替代：轴承、编码、驱动、减速机。

## 3. 选型必须冻结

- [ ] 确认是内转子，不是外转子套筒
- [ ] 额定 / 峰值扭矩、最高转速（内转子转速上限通常明显高于外转子）
- [ ] 定子外径与壳体过盈/胶槽；转子内径与轴/波发生器配合
- [ ] 气隙（内转子气隙在定子内圆与转子外圆之间）
- [ ] 与谐波波发生器的同轴、轴向限位
- [ ] 出线从定子外圆还是端面；是否挡阳极/轴承盖
- [ ] 齿槽转矩：低速精细轴要分数槽 / 斜槽口径

## 4. 配套关系

- **减速机：** 几乎默认要配。峰值扭矩 × 减速比不能打爆柔轮；输入转速不能超谐波限速。
- **散热：** 定子贴壳，热路过盈面就能走，风冷/液冷套都熟。连续转矩看壳体，不看「电机自己会散」。
- **编码：** 电机侧编码装在内转子轴上最自然。
- **结构：** 细长占轴向；图纸先给叠厚，不要和外转子扁关节混用同一壳体。

## 5. 验收要点

- 定子外圆、转子外圆尺寸；磁钢无崩裂
- 电阻、绝缘、反电势波形（抽检）
- 装进壳体后盘动无擦膛、齿槽手感
- 温升：按约定电流 × 约定壳体，不是悬空测

## 6. 已知坑

- 当外转子的「瘦版」直驱用，扭矩差一截，再加谐波才够。
- 转子与谐波波发生器同轴差，谐波寿命和噪音一起坏。
- 定子胶接固化温度过高，绝缘先伤。
- 线出方向与壳体干涉，现场剪线。

## 什么时候选它

首要目标是高转速、快加减速、长时间连续走、想用成熟「电机 + 谐波/行星」集成。腕、手、小臂优先。
