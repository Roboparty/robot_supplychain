# 磁钢

**大类：** [关节模组](../README.md) · **小类：** [无框力矩电机](./README.md)

转子上的永磁是气隙磁密的来源。无框默认 **表贴（SPM）**；外转子高速/高加速才认真谈粘接、护套或内置（IPM）。拓扑见 [README.md](./README.md)，铁心见 [core.md](./core.md)。

## 牌号怎么读

烧结钕铁硼口头「N52SH」一类：

| 段 | 含义 | 选型 |
|---|---|---|
| Nxx | 剩磁 `Br` 档（数字越大室温磁密越高） | 扭矩密度；高温会掉 |
| 后缀（H/SH/UH/EH…） | 矫顽力 / **最高工作温度** 档 | 关节连续温升、峰值电流去磁 |

只写 N52 不够：SH 和 UH 能扛的温度差一截。工作点要落在退磁曲线拐点以上，峰值电流 + 高温同时出现才是真去磁工况。

冻：`Br`、内禀矫顽力 `Hcj`、最高工作温度、镀层（镍铜镍 / 环氧等）。

## 表贴 vs 内置

| | SPM 表贴 | IPM 内置 |
|---|---|---|
| 气隙磁密 | 高，外圆好做正弦 | 受磁桥限制 |
| 弱磁 | 往往一般 | 凸极，弱磁更好 |
| 工艺 | 粘瓦 / 粘环，无框默认 | 冲片开槽埋磁，贵 |
| 风险 | 离心甩胶、锈、崩角 | 漏磁、机械更复杂 |
| 关节 | **内转子默认** | 外转子高速或要弱磁时再问 |

**极弧系数：** 一块磁钢占的电角度 / 极距。太大齿槽和谐波差，太小基波磁密掉。厂家给极弧或「磁钢宽度」，不要只数块数。

Halbach 阵列能抬气隙磁密、减轭厚，成本和不一致性都高，不是默认。

## 整环磁钢 vs 分块瓦片

| | **整环**（充磁环） | **分块瓦片** |
|---|---|---|
| 是什么 | 一圈烧结/粘结环，按极充磁 | 每极一块或几块瓦，胶到钢环上 |
| 气隙均匀 | 好做圆 | 接缝、块间公差会进齿槽 |
| 涡流 | 整环里涡流回路大，高速铜耗/热差 | **沿周向分块** 切断涡流，高频好一些 |
| 装配 | 套装快 | 逐片贴、极性检、工装多 |
| 损坏 | 崩一块可能整环报废 | 可单块返 |
| 无框 | 小外径内转子有时用环 | **更常见**：一极一块或多块 |

分块还有「一极再切成若干轴向/周向小块」专门为了涡流。极数 `2p` 是磁极对数口径，块数可以多于 `2p`。

外转子：磁钢在转子 **内圆**，离心力把瓦往外甩（脱离胶面）。高速要问胶、底涂、是否复合材料护套或不锈钢套；护套吃气隙。

## 与叠片、气隙

- 磁钢外圆（内转子）或内圆（外转子）对气隙；气隙标称约 **0.5 mm** 量级，见 [assembly.md](./assembly.md)。  
- 转子轭可以是叠片，也可以是实心钢环。表贴 + 实心轭在电频率高时轭里也有涡流，要问清楚。  
- 磁钢改贴导磁轴、省衬套，是中空放大的杠杆（README「更大中空」）。  

## 冻结清单

- [ ] SPM / IPM；整环还是瓦片；每极几块  
- [ ] 牌号（剩磁档 + 温度档）、镀层、最高工作温度  
- [ ] 极弧 / 块尺寸公差；充磁方向与极性标记  
- [ ] 粘接胶型号与固化；外转子要否护套  
- [ ] 去磁校核：峰值电流 × 约定壳体温度  
- [ ] 防锈：盐雾或湿热是否要（关节进油/进汗）  

## 验收

- 极性、块数、有无崩角裂纹  
- 表磁或反电势抽检（整机），不要只看入库外观  
- 胶层：缺胶、溢胶进气隙  
- 高加速台架后有无移位（外转子必做样品）  
- 锈点：镀层破口从边角起  

## 已知坑

- 室温 N52 样品认可，量产改 N42SH「更能扛温度」，Ke 掉一截。  
- 整环当瓦片的涡流损耗去对高速段温升。  
- 气隙里的溢胶当「气隙 0.5」设计，实际擦膛。  
- 外转子只比峰值扭矩，离心把瓦甩掉。  
- 磁钢批次混用，齿槽和不平衡力手感完全两套。
