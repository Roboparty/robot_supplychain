# 叠片与分瓣 / 整圆

**大类：** [关节模组](../README.md) · **小类：** [无框力矩电机](./README.md)

定子（常常还有转子轭）用硅钢片叠起来，是为了切断交变磁通里的涡流。片怎么冲、怎么叠、**整圆还是分瓣**，直接决定绕线工艺、槽满率、圆度和噪音。绕线见 [winding.md](./winding.md)，磁钢见 [magnet.md](./magnet.md)。

## 硅钢与叠压

| 项 | 口径 |
|---|---|
| 材料 | 无取向硅钢（关节默认）。取向硅钢是变压器逻辑，不要混 |
| 片厚 | 常见 0.20 / 0.27 / 0.35 mm。更薄：高频铁耗低、冲叠贵、毛刺和绝缘膜占比高 |
| 样机 | 线切割 / 激光切整叠，无冲模；毛刺、热影响区比量产冲片差，效率不能当量产数 |
| 量产 | 级进模冲片。开口模只适合中小批 |
| 叠压 | 扣片、铆、焊、胶粘。要冻 **叠压系数**（有效铁长 / 名义叠厚） |
| 绝缘 | 片间涂层；焊叠要把焊缝放在磁密低的轭外圆，否则局部短路涡流 |

叠厚 `LS` 是扭矩的主杠杆之一（见 [README.md](./README.md)），但叠厚加长、端部和壳体导热跟不上，连续转矩不按线性涨。

斜槽：在叠片上逐层错开，削齿槽。无框 `LS` 短，斜不出有效节距；优先换槽极，见 [slot-pole.md](./slot-pole.md)。

转子轭：表贴方案可以用 **叠片轭** 或 **实心钢环**。电频率高（极对数大 × 转速高）时实心轭涡流要问；外转子轭还要扛离心。

## 整圆式

**一整圈冲片（或一整圈线切）叠成闭环定子。** 齿和轭是连续的。

| 好 | 代价 |
|---|---|
| 磁路在轭上连续，接缝漏磁小 | 槽口必须留足，否则针绕进不去 |
| 圆度、刚度好做，气隙均匀 | **槽满率**通常低于分瓣飞叉 |
| 装配就是一个圆环往壳体里配 | 绕组坏了难单齿返修 |
| 热膨胀对称 | 大外径整圆冲模贵 |

绕线默认 **针绕** 或嵌线。协作关节里整圆 + 针绕很常见，连续转矩按这个槽满率来，不要拿分瓣样本曲线对。

## 分瓣式

**齿（有时连一段轭）先做成瓣，绕完线再拼成圆，或插进外轭环。** 集中绕组几乎是为这种工艺准备的。

常见两招：

1. **分齿 + 外轭圈套装：** 每个 T 形齿飞叉绕满，再扣进/粘进轭环。  
2. **瓣与瓣在轭上对接：** 若干块圆弧拼成 360°，接缝在轭。

| 好 | 代价 |
|---|---|
| 飞叉绕，**槽满率高**、端部好整形 | 接缝 = 气隙型磁阻，等效轭磁密/损耗变差 |
| 冲模可以是单齿，大电机也灵活 | 圆度、相邻齿距靠工装；气隙椭圆 → 齿槽和单边磁拉力 |
| 单齿可返 | 拼圆胶/扣片/焊接的强度和绝缘要过振动 |
| 节拍快、焊点方案好做多联绕 | 接缝处噪音、振动；导热路径在接缝断开 |

分瓣不是「性能免费升级」。同样电磁方案，分瓣往往 **多出来的铜**（槽满）和 **多出来的接缝磁阻** 在对冲；要以整机温升和齿槽验收，不能只看槽满率广告。

外转子的定子在内侧，分瓣拼圆后还要保证 **外圆**（气隙面）圆度，比内转子定子外圆贴壳更敏感。

## 怎么选

| 优先 | 更常选 |
|---|---|
| 低齿槽、圆度、中小外径、针绕产能现成 | **整圆** |
| 高槽满、短端部、大外径不想开整圆模、要飞叉产能 | **分瓣** |
| 样机几天要货 | 整圆线切叠 + 手工绕，先不要上分瓣工装 |

磁钢侧的「整环 / 瓦片」是另一刀，见 [magnet.md](./magnet.md)，不要和定子分瓣用同一个 PO 字段。

## 冻结清单

- [ ] 定子：**整圆 / 分瓣**；分瓣的瓣数、接缝在齿还是轭  
- [ ] 硅钢牌号与片厚；样机切法 vs 量产冲模  
- [ ] 叠压方式、叠压系数、名义 `LS`  
- [ ] 气隙面（内转子定子内圆 / 外转子定子外圆）圆度与同轴  
- [ ] 转子轭：叠片还是实心环  
- [ ] 分瓣：拼圆胶/机械锁、振动与温升验收口径  

## 验收

- 外径/内径、叠厚、毛刺（气隙面尤其）  
- 分瓣：拼缝目视、敲击松动、圆度  
- 装入壳体后盘动无擦膛（接缝鼓包最常见）  
- 空载铁耗或空载电流（有条件）与样品比，不要只称重量  

## 已知坑

- 分瓣样品槽满率 70%，量产改整圆针绕仍按同一连续转矩。  
- 整圆当分瓣修，单齿烧了整圈报废，交期爆炸。  
- 分瓣接缝对准气隙侧，当「看不出来」；齿槽和噪音上机才爆。  
- 样机线切叠片效率拿去写宣传，冲片量产铁耗更高。  
- 片厚从 0.2 改 0.35 不改驱动电频率预算，高速先热。
