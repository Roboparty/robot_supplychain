# 算力 / 主控

**大类：** [电子器件](./README.md)

## 1. 是什么

跑规划、推理、全身调度的计算单元：工控机、边缘 AI 模组、自研主板。

## 2. 在机器人里干什么

不负责关节电流环（那是 [驱动器](../01-joint-modules/driver.md)），负责轨迹、视觉、决策和总线主站。

## 3. 选型必须冻结

- [ ] CPU / NPU 算力、内存、存储
- [ ] 供电、功耗、散热
- [ ] 接口：EtherCAT 主站 / CAN / 相机 / USB
- [ ] 体积、安装、抗振
- [ ] 镜像与刷机方式

## 4. 配套关系

与驱动总线周期匹配。相机带宽和供电不要挤在同一条将要过流的线上。

## 5. 验收要点

上电、外设枚举、持续功耗温升、掉电重启。

## 6. 已知坑

- 只看 TOPS，接口不够当主站。
- 散热按桌面测，装进封闭躯干过热降频。
