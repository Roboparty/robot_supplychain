# 线材

**大类：** [电子器件](../README.md)

单根电线：导体截面积、绝缘皮、导体镀层。做成带插头的组件是 [线束](../harness.md)，可拆接口是 [接插件](../connectors/README.md)。

| 页 | 讲什么 |
|---|---|
| [AWG](./awg.md) | 线号数字的意思、截面积、铜阻；载流不是线号自带的 |
| [绝缘与镀层](./insulation.md) | 硅胶、PVC、铁氟龙、XLPE；镀锡 / 镀银 |

## 选型必须冻结

- [ ] AWG 或 mm²，二者写一个并注明是导体截面积  
- [ ] 绝缘：硅胶 / PVC / PTFE / XLPE；耐温  
- [ ] 导体镀层：裸铜 / 镀锡 / 镀银  
- [ ] 股数：活动关节用多股细丝，不用单股  
- [ ] **含绝缘的外径**。过 [谐波](../../01-joint-modules/reducer/harmonic/README.md) 中空只写 AWG 不够  
- [ ] 动力线和信号线分开；屏蔽要不要  

数字越大线越细。AWG 16 不是 16 mm²。

## 人形里怎么选

```text
电池、驱动母线，要软、要过关节
  → 硅胶线，截面积按压降和温升，不按商家印的「xx A」

箱内固定、不弯
  → PVC 或 XLPE，外径小、便宜

中空很紧、要耐焊接高温
  → 薄壁 PTFE，柔性不如硅胶

编码器、CAN、要抗干扰
  → 双绞 + 屏蔽，线号可以细，但屏蔽层怎么接地要冻
```

## 坑

- 按 AWG 名字里的习惯电流选线，成束、过关节后发烫。  
- 硅胶线外径粗，中空里塞不进。  
- 信号和动力挤在一根没有屏蔽的线里，编码跳。
