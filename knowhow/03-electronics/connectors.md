# 接插件

**大类：** [电子器件](./README.md)

## 1. 是什么

可拆的电连接：矩形、圆形、板对线、板对板。键位、锁扣、载流、针的镀层决定能不能反复拆。

## 2. 在机器人里干什么

模组电缆、电池口、调试口。尽量少种类，减少备件和插错。

## 3. 选型必须冻结

- [ ] 完整型号（含键位、针数、镀层）
- [ ] 载流与电压
- [ ] 锁扣 / 螺钉法兰
- [ ] 对插次数、IP 等级
- [ ] 国产替代是否要做保持力验证

## 4. 配套关系

线束厂、结构开孔、模组出线必须同一型号。电源与信号不要同一种外形除非键位物理防呆。

## 5. 验收要点

型号丝印、键位、锁扣力、针是否缩针。

## 6. 已知坑

- 替代料「能插」但保持力不够，振动后虚接。
- 电源口和调试口外形接近，现场插错。
