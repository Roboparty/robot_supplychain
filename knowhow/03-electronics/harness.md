# 线束

**大类：** [电子器件](./README.md)

## 1. 是什么

按图纸做的电缆组件：线径、长度、端子、护套、标签。不是散线现场剥皮。

## 2. 在机器人里干什么

关节动力/编码器线、电池到母线、传感器分支。过关节活动段要单独评弯曲寿命。

## 3. 选型必须冻结

- [ ] 线号（AWG 或 mm²）、绝缘与镀层、长度公差。见 [线材](./wire/README.md)
- [ ] 接头型号与键位（两端都写死）。见 [接插件](./connectors/README.md)
- [ ] 屏蔽、绞合、过孔护套
- [ ] 活动段弯曲半径与循环次数
- [ ] 标签与色标

## 4. 配套关系

和 [接插件](./connectors/README.md)、关节出线方向一起冻。过谐波中空的外径必须实测，XT30（2+2）按外壳而不是按线径。见 [XT30（2+2）](./connectors/xt30.md)。

## 5. 验收要点

导通、绝缘、对插键位、拉拔；禁止「看着能插」。

## 6. 已知坑

- 只给照片不给接头型号，到货对插毁针。
- 活动段按固定线束做，走几万步芯线断。
- 长度按 CAD 直线量，没留关节运动余量。
