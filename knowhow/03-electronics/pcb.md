# PCB / SMT

**大类：** [电子器件](./README.md)

## 1. 是什么

印制板设计 + 打样/小批贴片。原理图和 BOM 冻结前不要打板。

## 2. 在机器人里干什么

关节外置驱动板、传感器转接、躯干电源分配、通讯底板。

## 3. 选型必须冻结

- [ ] 原理图 / BOM 版本，电气会签
- [ ] 层数、阻抗、表面处理、钢网
- [ ] 长周期器件清单（>4 周标红）与替代规则
- [ ] 连接器型号与锁紧
- [ ] 固件烧录版本（板上有 MCU 时）

## 4. 配套关系

接插件与线束图纸同一型号。高压与电池相关要单独评爬电和隔离。

## 5. 验收要点

防静电包装、丝印、极性、通电枚举、关键接口电流。

## 6. 已知坑

- 结构件齐套，一颗驱动芯片还在 16 周。
- BOM 未冻就打板，SMT 后飞线。
- 样品用一套器件，小批偷偷替代。
