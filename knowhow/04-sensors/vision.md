# 视觉

**大类：** [传感器](./README.md)

## 1. 是什么

RGB、双目、深度相机、线激光等。镜头、对焦、触发、接口带宽都是规格。

## 2. 在机器人里干什么

导航、抓取感知、遥操作画面。和算力接口、头部机构一起冻。

## 3. 选型必须冻结

- [ ] 分辨率、帧率、视场、深度范围
- [ ] 接口（USB / 网口 / MIPI）、线长
- [ ] 同步触发、曝光
- [ ] 镜头固定方式、标定板流程
- [ ] 功耗与散热

## 4. 配套关系

头部运动时的走线见 [线束](../03-electronics/harness.md)。批次镜头差会导致标定不能复用。

## 5. 验收要点

出图、丢帧、深度空洞、固定安装下标定重投误差。

## 6. 已知坑

- 只看分辨率，接口在长线 USB 上掉帧。
- 镜头批次差，标定无法复用。
