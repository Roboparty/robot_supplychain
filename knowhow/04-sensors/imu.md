# IMU

**大类：** [传感器](./README.md)

## 1. 是什么

惯性测量：加速度 + 陀螺，常带磁力计。躯干姿态估计的主传感器之一。

## 2. 在机器人里干什么

平衡、状态估计。安装刚度和减振决定能不能用，不单看 datasheet 噪声。

## 3. 选型必须冻结

- [ ] 量程（摔倒冲击 vs 精细姿态）
- [ ] 接口与频率
- [ ] 安装位置、减振、电缆
- [ ] 是否要磁力计（电机漏磁环境要评估）

## 4. 配套关系

靠近大电流母线或电机时磁干扰。结构要给可重复的安装基准。

## 5. 验收要点

上电、静止零偏、轻敲是否饱和恢复。

## 6. 已知坑

- 用消费级 IMU 扛落地冲击。
- 装在可活动盖板上，测的是盖板振动不是躯干。
