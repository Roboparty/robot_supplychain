# 触觉传感器

**大类：** [传感器](./README.md)

## 1. 是什么

指面或掌面的接触、滑觉、分布式压力。形态从薄膜阵列到模组化指尖。

## 2. 在机器人里干什么

抓取闭合、打滑检测。没有场景清单时不要为参数买最贵阵列。

## 3. 选型必须冻结

- [ ] 覆盖面积、空间分辨率、力范围
- [ ] 曲面贴合还是平面
- [ ] 通信、标定、更换指面是否可维修
- [ ] 与 [灵巧手](../06-end-effector/dexterous-hand.md) 的机械/电气接口

## 4. 配套关系

指面磨损是耗材。协议要进手的控制周期，不能只出 USB 到另一台电脑。

## 5. 验收要点

分区响应、串扰、重复按压漂移。

## 6. 已知坑

- 只看点数，贴不到指腹曲面上。
- 标定在平桌，装到曲指全失效。
