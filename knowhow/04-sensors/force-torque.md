# 力 / 力矩传感器

**大类：** [传感器](./README.md)

## 1. 是什么

测一维力到六维力/力矩。可以是独立法兰盘，也可以集成在关节或踝。

## 2. 在机器人里干什么

足底接触、腕部作业力、关节力矩观测（若模组没自带）。量程太大，行走细信号被淹没。

## 3. 选型必须冻结

- [ ] 维数、量程、精度、过载倍数
- [ ] 机械法兰与电缆
- [ ] 协议与供电
- [ ] 标定：出厂还是现场、文件格式、多久一次
- [ ] 环境：冲击、温度

## 4. 配套关系

安装面平面度会吃精度。控制侧要约定滤波和零点漂移处理。

## 5. 验收要点

通电、零点、简易加载方向是否对、过载保护是否锁死。

## 6. 已知坑

- 买了传感器，没有标定工装和时间窗。
- 量程按破坏载荷选，走路信号像噪声。
