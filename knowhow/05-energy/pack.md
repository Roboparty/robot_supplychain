# PACK / BMS

**大类：** [能源](./README.md)

## 1. 是什么

电芯成组 + 保护板/BMS + 外壳 + 接插件。对外是一个可采购能源模块。运输仓储按电池规则。

## 2. 在机器人里干什么

整机能源。不合格 PACK 隔离，不得与结构件混放且不标识。

## 3. 选型必须冻结

- [ ] 电压平台、容量、放电倍率、循环目标
- [ ] 外形、重量、接插件、BMS 通信
- [ ] 保护：过充/过放/过流/过温
- [ ] 认证与运输（如 UN38.3，按实际阶段）
- [ ] 充电策略

## 4. 配套关系

与 [电源模块](../03-electronics/power.md) 的预充、欠压点一致。结构盒体避让和导热要冻。

## 5. 验收要点

外观、电压、保护板按规程抽检；序列号与容量标签。禁止在办公区胡乱短路测试。

## 6. 已知坑

- 样品放电好看，BMS 协议对不上整机。
- 航空/快递限制未提前问，交期失真。
- 不合格品与结构件混放，追溯失败。
