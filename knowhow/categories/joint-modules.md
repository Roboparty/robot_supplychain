# 关节模组

人形 BOM 里价值最高、交期最容易被卡的一块。电机 + 减速 + 编码 + 驱动（有时含力觉）做成标准单元。

## 规格冻结清单（G0 未齐不准询正式价）

- [ ] 额定 / 峰值扭矩、转速、电压平台
- [ ] 减速形式（谐波 / 行星 / RV / 准直驱）与背隙目标
- [ ] 编码器类型与通信（如 CAN / EtherCAT）
- [ ] 机械接口：法兰尺寸、定位销、电缆出线方向
- [ ] 重量、外径、中空走线是否必须
- [ ] 温升、防护、制动器有无
- [ ] 验收：台架曲线、噪音、空程、批次一致性

## 作业路径

```text
规格冻结 → 厂商短名单（≥2）→ 样品 / 台架数据
  → 小批 PO → 来料功能抽检 → 寿命与一致性跟踪
```

供应链主责商务、交期、备份供应商；关节规格与验收口径由关节 / 电控负责人会签。

## 已知坑

- 只比「额定扭矩」，峰值与持续温升上机才爆。
- 机械法兰能装，通信协议对不上，等于不能用。
- 独家 ODM 没有第二来源，图纸一改全线停。
- 宣传页把电池厂文案贴到关节类目——以样品数据与官网产品线为准。

## 验收要点

功能抽检：上电、通信、指向精度 / 空程、异常噪音。Conditional 不得用于承力关键轴，除非会签并限批次。
