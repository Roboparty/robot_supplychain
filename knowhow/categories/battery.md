# 电池

电压 / 容量 / 重量 / 认证没冻之前，不要进入「找最便宜 PACK」。

## 规格冻结清单

- [ ] 电压平台、容量、放电倍率、循环寿命目标
- [ ] PACK 外形、接插件、BMS 通信
- [ ] 认证与运输（UN38.3 等，按实际销售地）
- [ ] 仓储：隔离、禁混放未标识待检区

## 作业路径

```text
规格冻结 → 电芯 / PACK 短名单 → 样品安规与放电
  → 小批 → 来料外观 / 电压 / 保护板抽检
```

## 已知坑

- 样品放电好看，BMS 协议对不上整机。
- 不合格 PACK 与结构件混放，追溯失败。
- 航空 / 快递限制未提前问，交期失真。
