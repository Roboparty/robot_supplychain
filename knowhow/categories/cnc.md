# CNC 机加

样机结构件的主路径。材料、表面处理、公差必须写在图纸和申购单里，「按惯例」不算通过。

## 规格冻结清单

- [ ] 料号与图纸版本
- [ ] 材料牌号（如 6061-T6），禁止只写「铝」
- [ ] 表面处理（阳极色号、膜厚、是否导电）
- [ ] 关键尺寸与基准；配合件公差带
- [ ] 螺纹规格、是否要镶嵌件
- [ ] 数量：单套 × 套数 + 损耗
- [ ] 必须打样的件 vs 可直接小批的件

## 作业路径

```text
出图冻结 → 申购 → 询价 → 首件 FAI → PO → IQC 尺寸 / 外观 → 入库
```

改图升版后旧 RFQ 作废。

## 已知坑

- 公差全按「看起来精密」标，价格和交期一起爆炸；应把关键尺寸圈出来。
- 阳极外发未写入交期，样品「7 天」变成 14 天。
- 锐边 / 倒角未标，装配划线束、划手。
- 薄壁件变形，FAI 单件过、装成组件后孔系偏。

## 验收要点

对照图纸关键尺寸与表面处理。承力件 Fail 不得口头让步。
