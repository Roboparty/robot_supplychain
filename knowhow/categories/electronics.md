# 电子与线束

## 规格冻结清单

- [ ] 原理图 / BOM 版本；电气负责人会签
- [ ] 长周期器件清单（交期 > 4 周的标红）
- [ ] PCB 层数、阻抗、连接器型号与锁紧方式
- [ ] 线束：线径、端子、护套、长度公差、标签
- [ ] 静电 / 浪涌 / 绝缘要求（高压相关）

## 作业路径

```text
BOM 冻结 → 长周期先下 → PCB 打样 → SMT → 抽检 / 通电 → 入库
```

## 已知坑

- 结构件齐套了，一颗驱动芯片还在 16 周。
- 线束「看着能插」过检，对插次数高了松脱或针弯。
- 接插件国产替代未做对插与保持力验证。
