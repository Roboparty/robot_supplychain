# 门类 Knowhow

按「怎么买」分类，不按供应商名册。供应商短名单放作业仓库，这里只写**规格、工艺、坑、验收**。

| 门类 | 典型物料 | 默认路径 |
|---|---|---|
| [关节模组](joint-modules.md) | 一体化关节、谐波 / 行星 / RV、无框电机 | ODM 规格冻结 → 台架 → 小批 |
| [CNC 机加](cnc.md) | 铝件、法兰、壳体、关节座 | 出图冻结 → 打样 FAI → 小批 |
| [钣金](sheet-metal.md) | 电池盒、算力盒、支架 | 折弯公差与表面处理写死 |
| [电子与线束](electronics.md) | PCB、接插件、线束 | 长周期先锁；线束按图纸验收 |
| [传感器](sensors.md) | 力觉、触觉、IMU、视觉 | 接口协议与标定流程先冻 |
| [电池](battery.md) | 电芯 / PACK | 认证 + 运输仓储规则 |
| [灵巧手](dexterous-hands.md) | 末端、驱控 | 自由度 / 力控 / 通信先冻 |
| [轴承与标准件](bearings-hardware.md) | 轴承、紧固件 | 可跳过打样，不可跳过点数与等级 |
| [注塑 / 压铸 / 表面处理](tooling-and-surface.md) | 开模件、阳极、喷涂 | 样机阶段慎开模 |
| [3D 打印](3d-print.md) | 工装、手板 | 不默认承力量产 |
