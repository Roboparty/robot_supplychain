# 元器件卡片模板

每个小类 / 细分一页。复制后改标题和字段，挂到对应大类 README 的表里。

```markdown
# 名称

**大类：** … · **小类：** …

## 1. 是什么

一两段：原理、常见形态。

## 2. 在机器人里干什么

用在哪一轴 / 哪一部位，不替代什么。

## 3. 选型必须冻结

- [ ] 参数 1
- [ ] 参数 2

## 4. 配套关系

和电机、减速、编码、结构、电气怎么咬合。

## 5. 验收要点

来料 / 台架抽什么。

## 6. 已知坑

- …
```

复盘结论仍可追加 [knowhow-card.md](./knowhow-card.md)。
