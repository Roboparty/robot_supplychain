# 不合格 NCR

不合格不消失，必须留记录。

| Field | Value |
|---|---|
| NCR # | `NCR-YYYYMMDD-001` |
| 关联 PO / 料号 | |
| 缺陷描述 | |
| 处置 | 返工 / 退换 / 让步 / 报废 |

## 路径

| 路径 | 何时用 |
|---|---|
| 返工/挑选 | 缺陷可在厂内或供应商处消除 |
| 退货换货 | 无法用或供应商责任明确 |
| 让步接收 | 不影响安全/接口；必须书面、限批次 |
| 报废 | 无使用价值；成本记到对应 PO |

同一供应商重复 NCR → 降权或淘汰，在 G5 回写评分。
